# WisePet 设置手册

> 打开方式：右键点击桌面小猫 → **设置…**
> 所有设置**保存后立即生效**（个别项注明需重启），并自动保存到 `~/.WisePet/config.json`。

---

## 一、AI 服务（OpenAI 兼容）

决定小猫「有多聪明」。不填 Key 也能聊（走本地小脑，规则回复）。

| 配置项 | 说明 | 效果 / 注意 |
|---|---|---|
| **模型方案** | 下拉选择当前要编辑的方案；`＋` 新增、`－` 删除（至少保留一个） | 可以配多套不同的大模型，聊天时一键切换 |
| **方案名** | 方案的显示名 | 显示在聊天窗/输入条的「模型」下拉里，建议起好认的名字（如 `闪速`、`视觉`） |
| **Base URL** | OpenAI 兼容接口地址，一般以 `/v1` 或 `/v4` 结尾 | 例：智谱填 `https://open.bigmodel.cn/api/paas/v4` |
| **API Key** | 模型服务的密钥 | 只显示掩码不回填；留空表示保持原 Key 不变 |
| **Model** | 模型名 | 如 `glm-4-flash`；**发图片必须选视觉模型**（如 `glm-4v-flash`） |
| **Temperature** | 回答的随机度（0~2） | 越高越天马行空，越低越稳重 |
| **超时** | 请求超时秒数 | 模型慢就调大；超时会气泡报错并回兜底话术 |

**切换使用哪个方案**：聊天窗标题栏或点宠物弹出的输入条上，「模型」下拉直接选，立即生效。
点宠物聊天 / 历史窗 / 气泡提醒润色 / 新闻摘要 / 鼓励语，用的都是当前选中的方案。

## 三、宠物参数

| 配置项 | 默认 | 说明 / 效果 |
|---|---|---|
| **形象** | 橘猫 | 皮肤切换（橘猫/柴犬/小猴），需要有对应素材 |
| **走动速度** | 60 px/s | 自主溜达的速度，0~400 |
| **闲置间隔下限 / 上限** | 3~9 s | 每次自主行为（走动/伸懒腰/演示表情）之间随机休息多久 |
| **历史保留** | 20 轮 | 只控制**发给大模型的上下文窗口**（最近多少轮），不是磁盘记录——聊天记录全量保存在本机 `wisepet.db`，按天回看、跨日检索都不受它限制。调大：AI 更记得近期细节，但 prompt 变长、更费 token；调小：更省，旧内容靠下面的「会话摘要」和 AI 主动检索历史补足 |
| **聊天框空闲隐藏** | 30 s | 输入条无操作这么久后自动收起（打开/输入/发送都会重置计时）；**0 = 不自动隐藏** |
| **贴地** | 开 | 开：松手后自然落回屏幕底部；关：拖到哪停哪 |
| **漫游** | 开 | 自由漫游模式：不被钉在一条线上，可在桌面**任意高度**走动、睡觉、停留 |
| **瞬移间隔** | 30 s | 漫游时每隔多久「淡出→瞬移→淡入」柔和换一次地方；**0 = 关闭瞬移** |
| **活泼度** | 标准 | 安静 / 标准 / 活泼三档：缩放自主行为的间隔与概率，影响它多「闹腾」 |
| **进入特效** | 自动（按场景） | 登场动画风格，共 7 种；详见下方[十二、宠物进入特效](#十二宠物进入特效) |

> 提示：`漫游` 开着时，`贴地` 实际不生效（猫住在整张桌面）。

## 四、提醒陪伴

| 配置项 | 默认 | 说明 / 效果 |
|---|---|---|
| **弹窗停留** | 15 s | **所有通知气泡**的统一停留时长（3~120s）；到时未点「知道啦」自动消失 |
| **专注时长** | 25 min | 番茄钟默认时长：说「来个番茄钟」或右键菜单都用这个值；说「专注50分钟」则以说的为准 |
| **喝水 启用 / 间隔** | 开 / 45 min | 到点弹出「喝水提醒」卡片，配 AI 时话术会润色成小猫口吻 |
| **久坐 启用 / 间隔** | 开 / 60 min | 到点弹出「久坐提醒」卡片；与喝水各自独立计时、独立卡片 |
| **新闻播报 启用 / 间隔** | 开 / 60 min | 定时拉 RSS 科技资讯（默认 36氪/IT之家/少数派），配 AI 时播 120 字摘要，否则播标题列表；标题「新闻速览」 |
| **鼓励推送 启用 / 间隔** | 开 / 3 min | 定时来一句积极的话——古诗名句或夸奖；配 AI 时生成、未配走内置语录；标题「加油打气」 |
| **勿扰时段 启用 / 起止** | 关 / 12~14 点 | 时段内喝水/久坐/新闻/鼓励**顺延到时段结束**再推；一句话定时提醒不受影响 |

间隔类可设 **1 分钟起**，方便测试。提醒**到期必响**——全屏、最大化都不影响。

### 一句话定时提醒（不占设置项）

直接对聊天框说：
- 「5分钟后提醒我开会」「30s后提醒我站起来」「半小时后叫我拿快递」「14:30提醒我交日报」
- 「**每天**14:30提醒我交日报」→ 每日重复，重启后自动恢复
- 「**取消所有提醒**」→ 清空全部挂起与每日提醒

带标题「定时提醒」的通知卡，15 秒未确认自动消失。支持中英文时间单位（分钟/分钟/min/小时/h…）。
提醒已持久化（`~/.WisePet/reminders.json`），重启不丢。

### 番茄钟

对聊天框说「**专注25分钟**」「来个番茄钟」（默认 25 分钟，可指定时长）→ 到点弹出「专注结束」卡片；
右键菜单也有「番茄钟 25 分钟」入口。完成的专注自动计入陪伴统计（取消的不计）。

## 五、陪伴进阶

| 配置项 | 默认 | 说明 / 效果 |
|---|---|---|
| **语音说话** | 关 | 本地 TTS（Windows System.Speech / macOS say），提醒与回复可开口朗读；朗读前会剔除表情符号，零上传 |
| **朗读音量** | 100% | 0~100（Windows 生效；macOS 走系统音量） |
| **语速** | 0 | -10（慢）~ 10（快），0 为正常 |
| **系统通知** | 关 | 开启后提醒/新闻/鼓励等改走 **Windows 动作中心 / macOS 通知中心**（tile 固定显示 `WisePet`、标题为宠物名）；关闭则用宠物头顶自绘气泡。托盘不可用时自动回退气泡 |
| **周报推送** | 开 | 每周基于近 7 天本地聊天生成回忆录，配 AI 时润色、未配走本地文案；按自然周去重 |
| **推送日 / 推送时刻** | 周日 / 20 点 | 指定周报的推送时间；落在勿扰时段会顺延 |
| **成长体系** | 开 | 喂食 / 抚摸 / 聊天 / 跨日陪伴积累积分 → 等级与形态（外观徽章与缩放），右键「陪伴统计」查看 |
| **关系感** | 开 | 下面四项的**总开关**；一关整体退回旧版行为 |
| **主动惦记** | 开 | 从本地聊天里挑一条还没兑现的惦记（「明天打算…」「回头准备…」），启动 3 分钟后、每天最多一条「我还记得」气泡；排除命令句、刚说完的话、后来已完成的事 |
| **惦记入脑** | 开 | 把这件事悄悄写进系统提示词，让 AI 在话题自然相关时提起；**与「主动惦记」是独立开关**，可只关推送、仍聊得自然 |
| **情境化** | 开 | 周一早晨更有劲地小跑、刚结束专注伸懒腰、深夜去睡；话术里也注入「此刻情境」 |
| **可干预** | 开 | 摸一下会**真的打断**它当下在走/跑/睡（蹭回来伸个懒腰）；命令面板「叫一声小墨」会让它抬头看你 |
| **久别问候 / 久别阈值** | 开 / 20 小时 | 离开超过阈值再回来，开机问候改成本地确定的「好久不见」文案，按离开时长分档；未配 AI 也必定说得出 |
| **惦记条数** | 3 条 | 同时惦记几件没兑现的事；说「搞定了」会按话题自动消解对应的那件，含糊的「搞定了」只收尾最新一件 |

> 关系感四项全部只用本机事实（聊天时间戳、系统时钟、专注/勿扰状态），不联网、不画像、不猜测情绪。
> 惦记可以在命令面板「我还记得什么」随时查；它主动推的那条照旧受打扰预算与免打扰约束。

> 走系统通知时**没有「知道啦」按钮**（这是已知取舍：确认语义靠下次间隔重排）；
> 想要可确认的通知就保持「系统通知」关闭，用气泡。

## 六、体验与隐私

| 配置项 | 默认 | 说明 / 效果 |
|---|---|---|
| **预算开关 / 每日上限 / 单来源上限** | 开 / 12 条 / 4 条 | 限制程序**主动推送**的每日条数；用户主动发起的聊天回复与工具反馈不受拦截 |
| **免打扰** | 关 | 一键暂停全部主动推送；右键菜单也会显示当前状态 |
| **超限策略** | 用完就安静 | 可改「降频」：每被拦 N 次放行 1 条，不整天一点动静都没有 |
| **降频间隔** | 5 次/条 | 仅降频模式生效 |
| **行为驱动** | 开 | 按当前时段 / 专注 / 勿扰选择动作（清晨伸懒腰、专注时安静、夜间去睡），而不是纯随机轮播 |
| **长期记忆** | 开 | 你说的稳定事实（名字、喜好、住址、约定、项目…）由 AI 自动抽取，只存本机 `memory.json`，作为「权威事实」注入系统提示词；换个问法、隔几天再问也认得。关掉则既不抽取也不注入 |
| **检索上限** | 50 条 | 历史窗跨日全文检索一次最多返回条数（大小写不敏感、按时间倒序） |
| **写盘权限** | 每次确认 | 三级：每次确认 / 始终允许 / 一律拒绝；控制模型发起的创建文件、生成 PPT |
| **记住授权** | 关 | 允许在确认弹窗里勾「以后都允许」（记住后同类操作不再逐次确认） |
| **助理能力** | 开 | 下面三组的**总开关**；一关托付 / 资料索引 / 事件主动整体停用 |
| **可托付 / 盯文件间隔** | 开 / 30 s | 聊天直接说「盯着 D:/a.log，出现 ERROR 告诉我」或「每隔30分钟提醒我交周报」；本地解析立即建任务、跨重启不丢，读文件失败按退避重试并如实说明。只读取你显式给出的普通文件，拒符号链接与 >512KB 文件 |
| **资料索引 / 资料文件夹 / 注入片段** | 关 / 空 / 3 | 指定一个本机文件夹后，只索引白名单文本类型，聊天时按你问的问题检索片段注入 AI 上下文；索引只存本机、默认关闭、留空就绝不读任何文件 |
| **事件主动 / 情境上限** | 开 / 2 条每天 | 按本机事实主动关心：离开半小时回来、深夜还在用电脑、连着完成多轮专注；按规则×自然日去重、每天封顶，照旧受打扰预算约束 |
| **联网搜索** | 开 | 给 AI 加 `web_search` 工具查实时网页信息（新闻/天气/资料）；一关整体停用 |
| **搜索源** | 必应 Bing | 免 Key 默认（国内直连）；可切 DuckDuckGo（免 Key，国内通常不通）/ Tavily（海外，填 Key）/ 博查（国内效果好，填 Key） |
| **搜索 Key** | 空 | 所选搜索源的 API Key（密码框）；Bing/DuckDuckGo 不用填 |
| **高德 Key** | 空 | 高德「Web 服务」Key（[lbs.amap.com](https://lbs.amap.com) 免费申请）；填了 AI 才能用 `nearby_pois` 查**附近真实店铺**（名称/距离/电话）。未填时自动降级为网页搜索的近似结果 |
| **位置权限** | 开 | 给 AI 加 `get_location`（所在城市）与 `nearby_pois`（按坐标搜附近）；一关 AI 拿不到任何位置 |
| **授权策略** | 每次询问 | 每次询问（弹窗三选一）/ 总是允许（不再弹窗）/ 不允许（AI 拿不到位置）。定位优先用 **Windows 系统定位**（百米级，需在 Windows 设置 → 隐私 → 位置 开启），系统定位不可用时回落 IP 城市级；坐标只用于地图查询，聊天内容不上传 |

> 附近美食怎么搜得准：① Windows 开位置服务（百米级定位）；② 申请免费高德 Key 填进来
> （真实店铺 + 距离）。只有 IP 城市级 + 网页搜索时，AI 只能给出城市范围的泛化推荐。
> 位置授权弹窗选「拒绝」后 AI 不会再取位置，会引导你直接说出想查的城市。

### 弹窗突然都不见了，怎么查

按可能性从高到低：

1. **用了「深度工作」场景包**：它会关掉新闻 / 鼓励 / 周报，把喝水/久坐拉长到 45/50 分钟，
   并把打扰预算压到 `6 条/天、同类 2 条`。切换时气泡会当场列出被关掉的项。
   **恢复：右键 →「一键场景包」→「健康作息」**，一次把三个开关、额度（12/4）和推送间隔都还原。
2. **打扰预算当天的额度用完了**：`~/.WisePet/quiet.json` 记录 `total` 与 `by_source`，
   按自然日清零；额度耗尽时当天会给一条解释气泡（只给一次），不会一直静默。
   想多弹几次到本分区调「每日上限 / 单来源上限」，或直接关掉预算开关。
3. **开了免打扰**：右键菜单会显示「免打扰：开」，再点一次关掉。
4. **聊天输入条/历史窗开着**：会话期间自主行为会冻结（设计如此），按 `Esc` 关掉即恢复。

日志里搜 `quiet budget blocked push` 可以直接确认是不是被预算拦下。

| **Markdown 样式** | AI 回复自动渲染完整 markdown：标题/加粗/斜体/删除线/行内代码/代码块/引用/列表/表格/链接（链接点开走外部浏览器）；聊天窗与气泡同一套样式 |
| **拖动窗口大小** | 回复气泡与历史对话窗的**右下角**有尺寸手柄，拖动即可调整大小；拖过之后自动布局不会覆盖你的设置 |

> 写文件/生成 PPT **必须经过弹窗确认**，路径和内容你全程可见，点「执行」才落盘。

## 八、高级：config.json 手改项

文件位置 `~/.WisePet/config.json`（改完重启生效）。设置界面没有覆盖到的字段：

```jsonc
{
  "pet": {
    "run_speed_px_per_s": 150.0,   // 小跑速度
    "run_trigger_p": 0.25,         // 溜达时变成小跑的概率（0~1）
    "stretch_trigger_p": 0.2,      // 待机时伸懒腰的概率（0~1）
    "walk_max_s": 12.0,            // 单趟溜达最长时间（秒）
    "fall_speed_px_per_s": 900.0,  // 贴地模式的下落速度
    "activity": "normal",          // 活泼度：quiet / normal / lively（缩放自主间隔）
    "enter_effect": "auto"         // 进入特效：auto / random / 7 种固定值
  },
  "chat": { "idle_hide_s": 30.0 },  // 输入条空闲自动隐藏秒数，0 = 不隐藏
  "vitals": {
    "rules": {                     // 三维衰减（每小时）
      "hunger_per_hour": 4.2, "mood_per_hour": 2.0, "energy_per_hour": 3.0
    },
    "sad_threshold": 25.0,         // 心情低于此值会难过（SAD 表情）
    "danger_threshold": 15.0,      // 低于此值主动开口求助
    "help_cooldown_s": 1800.0,     // 两次求助的最小间隔
    "night_start_hour": 23, "night_end_hour": 7   // 夜间时段（犯困+回精力）
  },
  "news": {
    "sources": ["https://36kr.com/feed", "..."],  // RSS 源，可增删替换
    "max_headlines": 8             // 每次最多播几条
  },
  "bubble": { "duration_s": 15.0 },        // 弹窗停留，下限 3s
  "focus": { "default_min": 25.0 },        // 番茄钟默认时长
```

## 十、系统配置

与宠物本身无关的运行参数集中在这个分区（以后新增的系统级开关也放这里），
对应 `~/.WisePet/config.json` 的 `system` 分节。

| 配置项 | 默认 | 可选范围 | 说明 |
|---|---|---|---|
| **日志级别** | 常规（INFO） | 详细 DEBUG / 常规 INFO / 仅告警 WARNING / 仅错误 ERROR | 同时决定根 logger 级别；选「仅错误」时主档也只收 ERROR |
| **单文件上限** | 10 MiB | 1~100 MiB | 超过就分割；跨天也会额外封存一次 |
| **保留天数** | 3 天 | 1~30 天 | 滚动备份按 mtime 清理，正在写的文件不动 |
| **日志分档** | 开 | 开 / 关 | 关掉就只写主档，不再生成 `WisePet-error.log` |

改完点「保存」立即生效；`~/.WisePet/logs/WisePet.log` 里会留一行
`system log settings applied: level=… max_mb=… retention=… split=…` 供核对。
启动时 `main()` 会先读一次 `config.json` 再装配日志，所以这些值重启后也保持。
「为什么弹窗不见了」的排查步骤见 [六、体验与隐私](#六体验与隐私)。

## 十一、命令面板与本地数据管家

右键 →「命令面板…」打开，↑↓ 选择、回车执行、Esc 关闭。它把散落在右键菜单、
设置分区和托盘里的能力收成一处可搜索入口，不用再一层层找。

| 分类 | 可用命令 |
|---|---|
| 聊天 | 跟我聊天、历史对话、搜聊天记录（打开历史窗并聚焦搜索框） |
| 陪伴 | 排个提醒、番茄钟、恢复热闹（健康作息）、安静一会儿（深度工作）、为什么没弹窗、陪伴统计、**叫一声小墨**（打断它当下动作）、**我还记得什么**（查看当前惦记） |
| 身份 | **切换身份**（家人各养各的宠物，重启生效；也出现在右键菜单） |
| 数据 | 导出聊天记录（写到 `~/.WisePet/chat-export.md`）、本机数据占用、陪伴指标、清空本地埋点、**我记得你什么**（打开可勾选删除的时间线对话框）、最近执行的操作 |
| 托付 | **我的托付**（列出状态）、**取消全部托付** |
| 资料 | **重建资料索引**、**资料索引状态** |
| 系统 | 打开设置 |

**本地埋点**：只记录事件名与按天计数，从不写消息内容 / API Key / 文件路径，从不上传；
只保留近 30 天，命令「清空本地埋点」一键清干净（聊天记录与其它数据不动）。
「陪伴指标」显示首次对话是否达成、活跃天数、提醒关闭率、崩溃次数、事件总数。

**超限策略**（体验与隐私分区）：额度用完默认「安静」，也可改成「降频」——每被拦 N 次
放行 1 条，不再整天一点动静都没有。托盘菜单第一行会常驻显示当前场景、
新闻/鼓励/周报开关、今日推送用量与免打扰状态。

**素材规格自检**：`python tools/verify_assets.py` 校验三套皮肤各 10 动作 × 6 帧、
256×256 RGBA、帧间字节互异；`--strict` 可接 CI。

> **聊天记录已改用数据库**（只迁这一类数据，配置与状态仍是原来的 JSON、照旧可手改）。
> 首次启动会把旧的 `chat/YYYY-MM-DD.json` 一次性导入 `wisepet.db`，成功后归档到
> `chat/legacy/`（不删除）。因此「删掉某天文件就删掉那天记录」的旧做法不再适用：
> 想清空记录请删除 `wisepet.db`；想重新导入旧记录，把 `legacy/` 里的文件移回
> `chat/`、去掉 `.migrated` 后缀，再删掉 `wisepet.db` 重启即可。数据库损坏时会
> 自动备份成 `wisepet.db.bak-*` 并重建，不会崩。历史窗顶部的搜索框可跨所有日期检索。

## 十二、宠物进入特效

宠物「登场」（从隐藏到出现）时会播放一段动画，结束后再淡入现身。共 **7 种**主体风格，
全部是 `tech_effects.py` 里用 `QPainter` 程序化绘制，**零额外素材、零新依赖**。

7 种**共享同一套骨架**（与最初开机动画同源，FR v1.20 C37）：
汇聚能量环 + 旋转扫描环 → 各风格主体 → 收尾白核爆闪 + 十字准星 → 宠物 220ms 淡入。
统一 950ms 节奏、首尾渐入渐出，所以看起来是「同一个程序的出场」而不是 7 段拼盘。

| 特效 | 主体观感 | 默认触发场景（选「自动」时） |
|---|---|---|
| 粒子汇聚（spawn） | 粒子从四周汇聚到中心 | 开机启动 |
| 粒子爆开（burst） | 粒子向外爆开 + 双层冲击波环 | 排提醒 / 番茄钟 |
| 碎片拼合（puzzle） | 渐变三角碎片飞入拼成放射图案 | 手动可选 |
| HUD 扫描（terminal） | 悬浮扫描面板自上而下扫出数据网格 | 命令面板「跟我聊天」 |
| 能量揭幕（curtain） | 双向能量分界线扫过并汇合 | 命令面板切场景 |
| 能量波纹（ink） | 同心能量波纹由内向外扩散 | 从托盘恢复显示（auto 下实际随机） |
| 聚焦光束（magnifier） | 聚焦光束横向扫过 | 手动可选 |

**设置**（宠物参数 →「进入特效」）：下拉共 9 项——

- `自动（按场景切换）`：开机→粒子汇聚、唤聊→HUD 扫描、切场景→能量揭幕、提醒/番茄→粒子爆开；**「从托盘恢复」每次随机**选一种；
- `随机（每次不同）`：所有登场/触发都从 7 种里随机（能量波纹已重做，不再排除）；
- 其余 7 项为固定选择，想一直看某一种就选它。

**「随触发」规则**：宠物隐藏→显示时播完整登场（特效 + 淡入）；宠物**已可见**时触发
对应动作也照样播放该特效作反馈层（特效是独立透明叠加窗，不重播登场、不闪烁）——
所以日常宠物一直挂着也能看到不同风格，而不是只有开机/恢复两次登场才会播。
特效在 82% 处就提前通知宠物淡入，让淡入与收尾爆闪重叠，避免「特效没了才现身」的空白帧。

> 退出程序 / 隐藏到托盘时播放的是退场特效（粒子消散，700ms），与进入特效互不影响。

## 十三、常见问题

**Q：提醒到点没响？**
现在提醒「到期必响」，任何全屏/最大化都不会拦截。若还没响，看日志搜 `ReminderDueEvent` 或 `reminder`。

**Q：AI 回复说连不上 / 读不懂？**
Base URL 必须是 OpenAI 兼容地址；点设置里的「测试连接」验证。

**Q：发图片报错？**
当前选中的模型可能不支持视觉。切到带视觉能力的方案（如 `glm-4v-flash`）再发。

**Q：改了间隔怎么马上验证？**
间隔都支持 1 分钟起，保存后等一个周期即可；日志里能找到对应记录（如 `cheer published`、`news published`）。

**Q：开了「系统通知」后宠物头顶不弹气泡了？**
这是设计如此：通知改走 Windows 动作中心 / macOS 通知中心，气泡与「知道啦」按钮都不再出现。
想恢复可确认的气泡，到设置 →「陪伴进阶」关掉「系统通知」。托盘不可用时会自动回退气泡。

**Q：模型要写文件，怎么控制它？**
设置 →「体验与隐私」→「写盘权限」：默认「每次确认」（弹窗里能看到完整路径和内容），
也可设「始终允许」或「一律拒绝」；勾了「记住授权」还能在确认框里选「以后都允许」。
写过的文件在右键「撤销上一次写文件」可回滚一次，「最近执行的操作」可看历史记录。

**Q：弹窗一条都不来了？**
按 [六、体验与隐私](#六体验与隐私) 里的「弹窗突然都不见了，怎么查」逐项排查
（场景包 / 打扰预算 / 免打扰 / 会话冻结）。

**Q：它会记住我聊天里说的话吗？记在哪、怎么关？**
关系感只从**本机聊天记录**里挑「还没兑现的惦记」，记在 `presence.json` 的去重标记里，
不上传、不画像。想完全关掉：设置 →「陪伴进阶」→ 关「关系感」；
只想让它别主动开口、但仍聊得自然：只关「主动惦记」，保留「惦记入脑」。
命令面板「我还记得什么」可以看当前惦记着哪句。

**Q：隔了几天没开，它怎么知道我离开了多久？**
`presence.json` 存的是精确「上次出现」时间，启动早期就先读出来再刷新，
所以即使中间没开机也算得准；超过「久别阈值」就用本地文案问候，不需要联网或 AI。

**Q：怎么让它替我盯着一件事？**
直接聊天说「盯着 D:/a.log，出现 ERROR 告诉我」或「每隔30分钟提醒我交周报」。
本地解析立即建任务、不用等模型；只在关键词真出现时开口，读文件失败会重试并告诉你原因。
说「搞定了」就自动停，命令面板「我的托付」随时看状态、「取消全部托付」一次清空。
它**只读**你显式给出的普通文件，不执行、不写回、拒符号链接与大文件。

**Q：它会读我电脑上的文件吗？**
默认完全不读。只有你在设置 →「体验与隐私」里打开「资料索引」并**显式填了文件夹路径**，
它才会索引那个目录里的白名单文本类型；索引只存在本机 `knowledge.json`，不上传。
关掉开关或清空路径就清索引。命令面板「资料索引状态」可随时查看读了哪些文件。

**Q：想让它彻底忘掉某件事？**
命令面板「我记得你什么」打开时间线对话框，勾选对应条目点「删除所选」——是**真的从磁盘删掉**
（聊天记录按天删、记忆事实按 key 删、审计/托付按条删），不是隐藏。也可以「导出清单」先存档。

**Q：全家人想各养各的宠物怎么弄？**
不用注册任何账号：右键 →「切换身份…」输入名字（如「小明」），重启后就进入小明自己的宠物
——独立的宠物名、皮肤、记忆、成长等级，数据互不相通。之后每次启动会弹出「谁来了？」
点一下就进各自的宠物；也可以用启动参数 `--profile=小明` 直接进入。
**想沿用上次的身份，请点选择页里的「↩ 沿用上次身份：xxx」按钮**（若该身份设了 PIN 仍需验证）；
按 **Esc / 关窗 = 取消本次启动**，不会偷偷以管理员身份进程序——避免家人随手按 Esc 就绕过 PIN。
新建身份从零开始养；「默认身份」就是以前一直用的那只，随时可以切回去。

**Q：身份可以设密码吗？**
可以。新建身份时可以设一个 **PIN（4~12 位数字）**；带 🔒 标记的身份进入时需要输 PIN，
连续错 3 次锁 30 秒。它防的是**家人误入和随手翻看**——诚实地说，它防不了懂电脑的人
绕过界面直接读文件（数据就在本机文件里）。忘了 PIN：删除
`~/.WisePet/profiles/<名字>/pin.json` 即可重置（数据不动）。
