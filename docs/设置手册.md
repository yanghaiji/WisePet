# WisePet 设置手册

> 打开方式：右键点击桌面小猫 → **设置…**
> 所有设置**保存后立即生效**（个别项注明需重启），并自动保存到 `~/.WisePet/config.json`。

---

## 一、AI 服务（OpenAI 兼容）

决定小猫「有多聪明」。不填 Key 也能聊（走本地小脑，规则回复）。

| 配置项 | 说明 | 效果 / 注意 |
|---|---|---|
| **模型方案** | 下拉选择当前要编辑的方案；`＋` 新增、`－` 删除（至少保留一个） | 可以配多套不同的大模型，聊天时一键切换 |
| **方案名** | 方案的显示名 | 显示在聊天窗/输入条的「模型」下拉里，建议起好认的名字（如 `闪速`、`视觉`） |
| **Base URL** | OpenAI 兼容接口地址，一般以 `/v1` 或 `/v4` 结尾 | 例：智谱填 `https://open.bigmodel.cn/api/paas/v4` |
| **API Key** | 模型服务的密钥 | 只显示掩码不回填；留空表示保持原 Key 不变 |
| **Model** | 模型名 | 如 `glm-4-flash`；**发图片必须选视觉模型**（如 `glm-4v-flash`） |
| **Temperature** | 回答的随机度（0~2） | 越高越天马行空，越低越稳重 |
| **超时** | 请求超时秒数 | 模型慢就调大；超时会气泡报错并回兜底话术 |

**切换使用哪个方案**：聊天窗标题栏或点宠物弹出的输入条上，「模型」下拉直接选，立即生效。
点宠物聊天 / 历史窗 / 气泡提醒润色 / 新闻摘要 / 鼓励语，用的都是当前选中的方案。

## 三、宠物参数

| 配置项 | 默认 | 说明 / 效果 |
|---|---|---|
| **形象** | 橘猫 | 皮肤切换（橘猫/柴犬/小猴），需要有对应素材 |
| **走动速度** | 60 px/s | 自主溜达的速度，0~400 |
| **闲置间隔下限 / 上限** | 3~9 s | 每次自主行为（走动/伸懒腰/演示表情）之间随机休息多久 |
| **历史保留** | 20 轮 | AI 记得最近多少轮对话，越大越「记仇」也越费 token |
| **贴地** | 开 | 开：松手后自然落回屏幕底部；关：拖到哪停哪 |
| **漫游** | 开 | 自由漫游模式：不被钉在一条线上，可在桌面**任意高度**走动、睡觉、停留 |
| **瞬移间隔** | 30 s | 漫游时每隔多久「淡出→瞬移→淡入」柔和换一次地方；**0 = 关闭瞬移** |

> 提示：`漫游` 开着时，`贴地` 实际不生效（猫住在整张桌面）。

## 四、提醒陪伴

| 配置项 | 默认 | 说明 / 效果 |
|---|---|---|
| **弹窗停留** | 15 s | **所有通知气泡**的统一停留时长（3~120s）；到时未点「知道啦」自动消失 |
| **喝水 启用 / 间隔** | 开 / 45 min | 到点弹出「喝水提醒」卡片，配 AI 时话术会润色成小猫口吻 |
| **久坐 启用 / 间隔** | 开 / 60 min | 到点弹出「久坐提醒」卡片；与喝水各自独立计时、独立卡片 |
| **新闻播报 启用 / 间隔** | 开 / 60 min | 定时拉 RSS 科技资讯（默认 36氪/IT之家/少数派），配 AI 时播 120 字摘要，否则播标题列表；标题「新闻速览」 |
| **鼓励推送 启用 / 间隔** | 开 / 3 min | 定时来一句积极的话——古诗名句或夸奖；配 AI 时生成、未配走内置语录；标题「加油打气」 |
| **勿扰时段 启用 / 起止** | 关 / 12~14 点 | 时段内喝水/久坐/新闻/鼓励**顺延到时段结束**再推；一句话定时提醒不受影响 |

间隔类可设 **1 分钟起**，方便测试。提醒**到期必响**——全屏、最大化都不影响。

### 一句话定时提醒（不占设置项）

直接对聊天框说：
- 「5分钟后提醒我开会」「30s后提醒我站起来」「半小时后叫我拿快递」「14:30提醒我交日报」
- 「**每天**14:30提醒我交日报」→ 每日重复，重启后自动恢复
- 「**取消所有提醒**」→ 清空全部挂起与每日提醒

带标题「定时提醒」的通知卡，15 秒未确认自动消失。支持中英文时间单位（分钟/分钟/min/小时/h…）。
提醒已持久化（`~/.WisePet/reminders.json`），重启不丢。

### 番茄钟

对聊天框说「**专注25分钟**」「来个番茄钟」（默认 25 分钟，可指定时长）→ 到点弹出「专注结束」卡片；
右键菜单也有「番茄钟 25 分钟」入口。完成的专注自动计入陪伴统计（取消的不计）。

## 六、高级：config.json 手改项

文件位置 `~/.WisePet/config.json`（改完重启生效）。设置界面没有覆盖到的字段：

```jsonc
{
  "pet": {
    "run_speed_px_per_s": 150.0,   // 小跑速度
    "run_trigger_p": 0.25,         // 溜达时变成小跑的概率（0~1）
    "stretch_trigger_p": 0.2,      // 待机时伸懒腰的概率（0~1）
    "walk_max_s": 12.0,            // 单趟溜达最长时间（秒）
    "fall_speed_px_per_s": 900.0   // 贴地模式的下落速度
  },
  "vitals": {
    "rules": {                     // 三维衰减（每小时）
      "hunger_per_hour": 4.2, "mood_per_hour": 2.0, "energy_per_hour": 3.0
    },
    "sad_threshold": 25.0,         // 心情低于此值会难过（SAD 表情）
    "danger_threshold": 15.0,      // 低于此值主动开口求助
    "help_cooldown_s": 1800.0,     // 两次求助的最小间隔
    "night_start_hour": 23, "night_end_hour": 7   // 夜间时段（犯困+回精力）
  },
  "news": {
    "sources": ["https://36kr.com/feed", "..."],  // RSS 源，可增删替换
    "max_headlines": 8             // 每次最多播几条
  },
  "bubble": { "duration_s": 15.0 } // 同「弹窗停留」，下限 3s
}
```

改坏了也不用怕：所有字段解析失败都会回落默认值，不会崩。

## 七、文件位置

| 内容 | 路径 |
|---|---|
| 配置 | `~/.WisePet/config.json` |
| 聊天记录 | `~/.WisePet/wisepet.db`（SQLite 单文件） |
| 旧聊天记录归档 | `~/.WisePet/chat/legacy/*.json.migrated` |
| 日志（完整时间线，INFO+） | `~/.WisePet/logs/WisePet.log` |
| 日志（告警与错误，WARNING+） | `~/.WisePet/logs/WisePet-error.log` |
| 宠物状态快照 | `~/.WisePet/pet_state.json` |

（`~` 即 `C:\Users\你的用户名`）

> **日志分等级 + 保留期**：主档 `WisePet.log` 收 INFO 及以上（完整时间线），
> `WisePet-error.log` 只收 WARNING 及以上，排障直接看后者。两档各自在
> **单文件超过 10 MiB** 时分割，跨天也会封存一次；滚动备份只保留**近 3 天**，
> 超期自动删，正在写的文件不动。搜 `ReminderDueEvent`、`cheer published`、
> `behavior … -> …` 这类关键字用主档；查异常、超时、协议错误用错误档。
> **这些值现在都可以改**：设置 →「系统配置」分区，保存后立即热重建日志，无需重启。

## 七之二、系统配置

与宠物本身无关的运行参数集中在这个分区（以后新增的系统级开关也放这里），
对应 `~/.WisePet/config.json` 的 `system` 分节。

| 配置项 | 默认 | 可选范围 | 说明 |
|---|---|---|---|
| **日志级别** | 常规（INFO） | 详细 DEBUG / 常规 INFO / 仅告警 WARNING / 仅错误 ERROR | 同时决定根 logger 级别；选「仅错误」时主档也只收 ERROR |
| **单文件上限** | 10 MiB | 1~100 MiB | 超过就分割；跨天也会额外封存一次 |
| **保留天数** | 3 天 | 1~30 天 | 滚动备份按 mtime 清理，正在写的文件不动 |
| **日志分档** | 开 | 开 / 关 | 关掉就只写主档，不再生成 `WisePet-error.log` |

改完点「保存」立即生效；`~/.WisePet/logs/WisePet.log` 里会留一行
`system log settings applied: level=… max_mb=… retention=… split=…` 供核对。
启动时 `main()` 会先读一次 `config.json` 再装配日志，所以这些值重启后也保持。

### 弹窗突然都不见了，怎么查

按可能性从高到低：

1. **用了「深度工作」场景包**：它会关掉新闻 / 鼓励 / 周报，把喝水/久坐拉长到 45/50 分钟，
   并把打扰预算压到 `6 条/天、同类 2 条`。切换时气泡会当场列出被关掉的项。
   **恢复：右键 →「一键场景包」→「健康作息」**，一次把三个开关、额度（12/4）和推送间隔都还原。
2. **打扰预算当天的额度用完了**：`~/.WisePet/quiet.json` 记录 `total` 与 `by_source`，
   按自然日清零；额度耗尽时当天会给一条解释气泡（只给一次），不会一直静默。
   想多弹几次到设置 →「体验与隐私」调「每日上限 / 单来源上限」，或直接关掉预算开关。
3. **开了免打扰**：右键菜单会显示「免打扰：开」，再点一次关掉。
4. **聊天输入条/历史窗开着**：会话期间自主行为会冻结（设计如此），按 `Esc` 关掉即恢复。

日志里搜 `quiet budget blocked push` 可以直接确认是不是被预算拦下。

## 九、命令面板与本地数据管家

右键 →「命令面板…」打开，↑↓ 选择、回车执行、Esc 关闭。它把散落在右键菜单、
设置分区和托盘里的能力收成一处可搜索入口，不用再一层层找。

| 分类 | 可用命令 |
|---|---|
| 聊天 | 跟我聊天、历史对话、搜聊天记录（打开历史窗并聚焦搜索框） |
| 陪伴 | 排个提醒、番茄钟、恢复热闹（健康作息）、安静一会儿（深度工作）、为什么没弹窗、陪伴统计 |
| 数据 | 导出聊天记录（写到 `~/.WisePet/chat-export.md`）、本机数据占用、陪伴指标、清空本地埋点、我记得你什么、最近执行的操作 |
| 系统 | 打开设置 |

**本地埋点**：只记录事件名与按天计数，从不写消息内容 / API Key / 文件路径，从不上传；
只保留近 30 天，命令「清空本地埋点」一键清干净（聊天记录与其它数据不动）。
「陪伴指标」显示首次对话是否达成、活跃天数、提醒关闭率、崩溃次数、事件总数。

**超限策略**（体验与隐私分区）：额度用完默认「安静」，也可改成「降频」——每被拦 N 次
放行 1 条，不再整天一点动静都没有。托盘菜单第一行会常驻显示当前场景、
新闻/鼓励/周报开关、今日推送用量与免打扰状态。

**素材规格自检**：`python tools/verify_assets.py` 校验三套皮肤各 10 动作 × 6 帧、
256×256 RGBA、帧间字节互异；`--strict` 可接 CI。

> **聊天记录已改用数据库**（只迁这一类数据，配置与状态仍是原来的 JSON、照旧可手改）。
> 首次启动会把旧的 `chat/YYYY-MM-DD.json` 一次性导入 `wisepet.db`，成功后归档到
> `chat/legacy/`（不删除）。因此「删掉某天文件就删掉那天记录」的旧做法不再适用：
> 想清空记录请删除 `wisepet.db`；想重新导入旧记录，把 `legacy/` 里的文件移回
> `chat/`、去掉 `.migrated` 后缀，再删掉 `wisepet.db` 重启即可。数据库损坏时会
> 自动备份成 `wisepet.db.bak-*` 并重建，不会崩。历史窗顶部的搜索框可跨所有日期检索。

## 八、常见问题

**Q：提醒到点没响？**
现在提醒「到期必响」，任何全屏/最大化都不会拦截。若还没响，看日志搜 `ReminderDueEvent` 或 `reminder`。

**Q：AI 回复说连不上 / 读不懂？**
Base URL 必须是 OpenAI 兼容地址；点设置里的「测试连接」验证。

**Q：发图片报错？**
当前选中的模型可能不支持视觉。切到带视觉能力的方案（如 `glm-4v-flash`）再发。

**Q：改了间隔怎么马上验证？**
间隔都支持 1 分钟起，保存后等一个周期即可；日志里能找到对应记录（如 `cheer published`、`news published`）。
