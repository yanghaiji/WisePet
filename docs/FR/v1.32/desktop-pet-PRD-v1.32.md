# 桌面宠物 WisePet PRD v1.32

- 版本：v1.32
- 状态：已实现（待评审）
- 日期：2026-11
- 性质：增量需求（身份体验完善 + 家庭 AI 治理 + 检索策略修正），不回改历史版本

## 1. R1 切换身份即时生效（不再要求手动重启）

- 「谁来了？」选中后：保存当前状态 → `QProcess.startDetached` 拉起新身份进程
  （独立守卫端口，可与旧进程并行）→ 当前宠物说一句话后退场退出
- 用户看到的是「宠物退场 → 新宠物进场」，无需手动重启；
- 兼容打包与开发两种形态（frozen 走 exe 自身，开发走 python + main.py）。

## 2. R2 贴纸风输入对话框

- 新增 `ui/input_dialog.py`：与身份选择页同一套视觉，支持密码模式与
  **卡片内红字错误提示**（替代原生 QInputDialog 的弹窗套弹窗）；
- 身份名输入、PIN 进入、设置 PIN、删除确认全部换用。

## 3. R3 家庭共享 AI + 每日配额（防孩子过度消费）

- 家长配一次：命令面板「共享我的 AI 给全家」→ 当前 AI 写入全局 `shared_ai.json`
  （Key 只存本机全局文件，**不下发到孩子身份的配置里**）；
- 孩子身份设置里勾「使用家庭共享 AI」→ 生效配置切换为共享那份（`_effective_ai()`），
  家长改一次 Key 全家生效；各自也可以保留自己的配置（不勾即用自己）；
- **每日配额**：设置 →「每日 AI 上限」（次/天，0=不限）；每轮 AI 请求计数
  （`ai_usage.json`，只记次数不记内容），超限后**回落本地小脑**并当日提示一次。

## 4. R4 删除身份（带验证与防误删）

- picker 新增「🗑 删除身份…」：输入身份名 → PIN 验证（若设）→ **完整输入身份名二次确认**
  → 删除整个数据目录；默认身份不可删除；删除当前 active 自动清空 active；
- 三重防误删：名字校验 + PIN + 明示「不可恢复」。

## 5. R5 检索策略修正（不再替 AI 丢掉真实记忆）

- 跨日检索上限 50 → **200**；RAG 注入片段 top_k 3 → **6**、单片段 600 → 800 字符、
  总量 2200 → 3200 字符；
- 自由事实 TTL 90 天 → **365 天且可配置（0 = 永不衰减）**，提示词条数 8 → 12；
- 关键理念落地：**固定注入只保留「最近的摘要」**，完整记忆永远可以通过 agent 的
  `recall_memories / search_history / search_knowledge / read_file` 工具检索——
  检索多少条、要不要再查，交给 AI 自己决定（agentic retrieval），而不是预设上限；
- RAG 注入提示词显式引导模型继续用工具深查。

## 6. 验收项

| 组 | 验收 |
|---|---|
| AC-SWITCH-1 | 选中身份 → startDetached 带 `--profile` → active 更新 → 当前进程退场 |
| AC-INPUT-1 | PIN/文本对话框：密码回显、卡片内错误提示、取消返回 None |
| AC-FAM-1 | 共享保存/读取；`_effective_ai` 勾选后切到共享配置；未配置共享时回落自己 |
| AC-FAM-2 | 每日配额：计数、超限回落本地小脑、当日提示一次、次日恢复 |
| AC-DEL-1 | 删除需 PIN + 名字一致；默认身份不可删；active 自动清理 |
| AC-MEM-1 | 检索召回放大；TTL=0 永不衰减；提示词带 agentic 检索引导 |
| AC-SAFE-1 | 窗口 C++ 对象销毁后 `_sync_window` 安全跳过（生产健壮性） |

## 7. 范围外

- 不做数据加密（PIN 派生密钥加密 profile 文件，作为后续可选增强）；
- 不做跨进程通信（切换是单向接力，不走 IPC 回传）。
