# 桌面宠物 WisePet PRD v1.33

- 版本：v1.33
- 状态：已实现（待评审）
- 日期：2026-11
- 性质：增量需求（联网搜索 + 位置感知 + 周边搜索 + agent 真流式），不回改历史版本

## 0. 背景与动机

真机反馈「让小墨查附近的美食」得到的是幻觉回复（"搜索工具出了点问题"），实证为
**项目从未有过联网工具**——模型只能编造或兜底。真机多轮定位出四层问题，本版一次补齐：

1. 没有任何联网搜索工具（连工具都没注册，模型只能瞎说）；
2. "附近xx"类查询的定位只有 IP 城市级，搜不出具体店铺；
3. agent 循环整段非流式，工具轮次多时用户干等 20 秒才一次性出字（FR v1.30 §范围外
   的"流式 tool_calls"在本版补上）；
4. 弱模型在无工具结果时编造店名（需提示词约束）。

隐私口径与既有"零上传"卖点的关系：联网搜索 / 定位均为**用户主动配置 + 显式授权**
的可选能力，聊天内容不随搜索上传；位置授权三态持久化（每次询问 / 总是允许 / 拒绝）。

## 1. R1 联网搜索（web_search 工具）

- agent 工具循环新增 `web_search`（query 必填）：查最新的网页资讯（新闻/天气/资料）；
- 四家供应商可配置切换：**bing（免 Key，国内直连，默认）** / duckduckgo（免 Key，
  国内通常不通）/ tavily（海外，填 Key）/ bocha（国内效果好，填 Key）；
- SSL 信任链合并 certifi + Windows 系统 CA/ROOT 证书：本机代理 / 安全软件做 HTTPS
  拦截时签发系统信任的自签证书，纯 certifi 会 CERTIFICATE_VERIFY_FAILED（真机实锤）；
- 搜索失败（网络不通 / 服务不可用）返回人话兜底，要求模型如实告知、不编造信息。

## 2. R2 位置感知（get_location 工具 + 两级定位）

- 新增 `get_location` 工具：返回用户当前大致位置（城市/坐标），用于附近搜索与天气；
- **两级定位，自动择优**：
  - 精确级：Windows 系统定位（Qt Positioning，WiFi/GPS，实测误差约 85 米）；
    模块缺失（PySide6 精简安装无 QtPositioning）时自动不可用；
  - 城市级：IP 归属地（ip-api / ipapi.co 免 Key）；精确定位无城市名时补一次 IP 查询标注城市；
- **授权闸门**（get_location / nearby_pois 共用）：设置三态 `ask / granted / denied`；
  `ask` 时弹窗三选一（仅本次允许 / 总是允许 / 拒绝），"总是允许/拒绝"持久化进
  config，"拒绝"后模型必须引导用户直接说出城市，不得强行再取；
- 缓存：精确定位 10 分钟、IP 城市 6 小时；系统定位失败有 10 分钟退避（位置服务
  未开启时不每轮干等超时）；
- 坐标口径：系统定位产出 WGS-84，自动转换为 GCJ-02（国内地图服务要求）。

## 3. R3 周边搜索（nearby_pois 工具 + 无 Key 降级）

- 新增 `nearby_pois`（keyword 必填，radius_km 可选，默认 3km 上限 10km）：
  按精确定位坐标调高德「周边搜索」API，返回 名称/地址/距离/电话 的真实店铺列表；
  用户问「附近的xx」时必须走本工具，禁止编造店名；
- **无 Key 降级**：未配置高德 Key 时自动转网页搜索（城市 + 关键词 + 大众点评/推荐），
  结果标注"近似结果、仅供参考"交模型整理，并在结尾转告"填免费高德 Key 可升级为
  精确店铺列表"；
- 高德 Key 无效（INVALID_USER_KEY）时给出指向设置的人话提示；配额/接口失败降级为空
  结果 + 兜底话术，不崩对话。

## 4. R4 agent 真流式（取代 FR v1.30 的拟流式）

- 网关新增 `chat_with_tools_stream`：SSE 流式解析 `delta.content`（逐字回调上屏）与
  `delta.tool_calls`（按 index 分片聚合，OpenAI 协议标准格式，智谱兼容）；
- AgentRunner 每步模型调用走流式：**工具循环中途的过渡语**（如"让我查一下"）也实时
  露出；网关拒绝流式工具协议（PROTOCOL）时单次回落非流式，不影响本轮结果；
- ChatService 增量直接上屏（首次增量切 REPLYING），已流过的内容不再用拟流式重复播；
  网关完全不支持流式时回落拟流式（FR v1.30 行为），取消语义不变。

## 5. R5 防编造约束

- `nearby_pois` 工具描述与系统提示词能力声明明确：报告具体餐厅/店铺名必须来自
  工具返回的真实结果；没有工具结果时只能泛泛介绍，绝不能编造店名；
- `web_search` 工具描述引导分流：本地生活类查询改用 nearby_pois。

## 6. 设置项

设置 → 体验与隐私 新增五项：**联网搜索**（开关）、**搜索源**（四选一下拉）、
**搜索 Key**（密码框）、**高德 Key**（密码框）、**位置权限**（开关）+ **授权策略**
（每次询问 / 总是允许 / 不允许）。全部保存即生效、持久化进 config.json。

## 7. 验收项

| 组 | 验收 |
|---|---|
| AC-WEB-1 | 四供应商按配置生效；配置对象与纯字符串两种回调形态兼容；非法值回落默认 |
| AC-WEB-2 | Bing 免 Key 真机可达（中文查询返回可用结果）；摘要 HTML 实体还原 |
| AC-WEB-3 | 搜索失败返回兜底文案，不崩对话；供应商 Key 缺失给出设置指引 |
| AC-GEO-1 | 系统定位优先（真机 43.862,125.243 / 误差 85 米）；WGS-84→GCJ-02 偏移正确 |
| AC-GEO-2 | 系统定位失败 10 分钟退避后回落 IP 城市；两级缓存各自生效 |
| AC-GEO-3 | 授权三态：ask 弹窗三选一、granted/denied 持久化；拒绝后模型不得再取位置 |
| AC-POI-1 | 有 Key 走高德周边搜索返回真实店铺；Key 无效给出设置指引 |
| AC-POI-2 | 无 Key 自动降级网页搜索（带城市关键词），标注近似结果并转告配置方法 |
| AC-STREAM-1 | agent 最终回复逐字上屏（真流式）；过渡语实时露出 |
| AC-STREAM-2 | 网关拒流式时单次回落非流式；零增量时回落拟流式，无重复播报 |
| AC-CFG-1 | 五个设置项保存即生效、持久化、重启回读；手改 json 越界值被钳制 |

## 8. 范围外

- 不做 Windows 位置服务的系统设置引导页（用户在 Windows 设置里自行开启）；
- 不做逆地理编码（精确定位只给坐标 + IP 城市名，不解析街道）；
- 不接百度/腾讯地图等其他 POI 服务（高德单供应商已覆盖场景）；
- 不做搜索结果缓存（Bing/DDG 实时查询，页级去重已做）。
