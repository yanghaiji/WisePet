# 桌面宠物 PRD v1.6 —— 回复来源必须可观测

> 本文件只记录**相对 v1.5 的需求变更**（四层架构、本地小脑、AI 链路错误分类均不重复）。
> 按 `docs/规约.md`：修订不回改历史版本；本版**补充 v1.0 §M4 与 v1.5 §2**，不改变任何已确认的行为契约。

## 0. 变更清单

| 编号 | 变更 | 类型 | 来源 |
| --- | --- | --- | --- |
| C8 | 用户**分不清气泡里的话是谁说的**：本地小脑与远端模型都走同一套拟流式逐段上屏，外观完全一致。要求每一次聊天请求在日志里留下可判读的**来源、目标地址、耗时与回复摘要**，且本地链路要给出命中的路由 | 补充 v1.0 §M4 | 用户反馈「加点请求模型的日志把 我也不知道是模型返回的回答 还是他自己的回答」 |

## 1. 改前现状（可核对）

聊天链路自己**一行日志都不写**，与「谁作答」相关的信息只有两处间接线索：

| 现象 | 改前 | 为什么不够 |
| --- | --- | --- |
| 配了 Key | 只有 `httpx` 打的 `POST …/chat/completions "HTTP/1.1 200 OK"` | 看不出对应哪一次提问、看不出回了什么、看不出等了多久 |
| 没配 Key | 完全没有任何请求日志（本地是纯计算，不发网络请求） | 用户只看到「没有日志」，反而以为配置坏了 |
| 两种情况 | 气泡长得一样（都是逐段出现） | 无法判断这条是模型答的还是小脑答的——正是本次要解决的点 |

## 2. 需求条目

- **R1 一问一答各留一行，且必须带来源**。每条消息至少产生 `source=ai` 或 `source=local` 的请求行与结果行；两条链路的日志必须能一眼区分。
- **R2 AI 请求行要说清打到哪里**。`model`、完整 `endpoint`（Base URL + `/chat/completions`）、消息条数、prompt 总字符数——用于判断「地址填对了没」「上下文带了多少」。
- **R3 AI 结果行要说清快慢与内容**。段数、回复字符数、**首段耗时**、总耗时、回复摘要（前 60 字）。首段耗时用于区分「连上半天的不出字」与「出字了但说得慢」。
- **R4 本地结果行要说清是谁答的**。带命中的路由名（`greet` / `stress` / `knowledge` / `follow_up` / `fallback` 等），使「这条话术来自哪段路由」可回溯。
- **R5 启动与保存配置时各锚定一行**。打印当前由谁作答（`chat brain=ai|local`），因为逐条 `source` 需要一个上下文起点；改了 AI 配置后必须能立刻看到锚点变化。
- **R6 失败同样带来源**。沿用 v1.5 的错误分类，失败行形如 `source=ai failed [protocol] …`，且**不产生结果行**（避免留下「成功但内容为空」的误导记录）。

## 3. 验收标准

- **AC-LOG-1**：未配 API Key 问一句 → 日志出现 `source=local intent=… preview=…`，且整轮不出现 `source=ai`。
- **AC-LOG-2**：配好 Key（`https://open.bigmodel.cn/api/paas/v4` + `glm-4-flash`）问同一句 → 出现 `source=ai request model=… endpoint=…` 与 `source=ai done … first_chunk=… preview=…` 两行，endpoint 与设置里填的地址一致。
- **AC-LOG-3**：把两种配置的 preview 并排看，能直接判断「哪条是模型的话、哪条是小脑的话」——这是本次变更的**唯一硬性目检项**。
- **AC-LOG-4**：Base URL 填错（如 `…/api/anthropic`）→ 只有 request 行 + `failed [protocol]` 行，没有 done 行。
- **AC-LOG-5**：日志里不出现 API Key 原文（v1.0 的两道脱敏防线继续生效，新增字段只打印 model 与地址）。

## 4. 边界与不承诺

- **不在气泡上打来源标记**（例如「[本地]」前缀）。桌宠的气泡要保持像它在说话，可观测性放在日志侧。
- **不新增日志文件、不加级别开关、不做日志检索界面**。日志路径已在启动时打印（`bootstrapping (log=…)`）。
- **preview 只截 60 字**，不是全文；换行折成 `↘` 保证一条回复只占一行。要全文请直接在气泡里看。
- **代价如实登记**：回复摘要从此会以截断形式落进本机日志文件（`logs/ai-bot.log`，1MB × 3 轮转）。用户输入的原文不落盘，只落宠物说出去的话。
- 不承诺本地链路的耗时可比：本地是纯计算，首句耗时含一次分词词典惰性加载，`elapsed` 会随冷/热差异很大，故本地行不记首段耗时。
