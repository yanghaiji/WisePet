# 桌面宠物 WisePet 需求设计 v1.9

- **对应技术设计**：[NFR v1.10](../../NFR/v1.10/desktop-pet-tech-design-v1.10.md)
- **上一版本**：[v1.8](../v1.8/desktop-pet-PRD-v1.8.md)
- **状态**：待评审
- **变更性质**：增量修订（仅描述相对 v1.8 的变化）

## 0. 背景

v1.8 把聊天做成了一个"点宠物即弹出的常驻大窗"，用户真机看到后否掉了这个形态：

1. 大窗是系统标题栏 + 裸控件的默认外观，与桌宠的扁平贴纸风割裂，判定"太丑"。
2. **不希望聊天时直接弹出大窗**——原本点宠物只是浮一条单行输入条，交互轻，不该变成一整块面板。
3. 历史会话应当有独立入口：**右键菜单 → 历史对话…** 才查看，而不是跟着聊天一起出现。
4. 正常聊天恢复原样（单行输入条 + 头顶气泡）。

因此 v1.8 C13 的"会话窗即聊天入口"被本版本替换；按天保存、会话状态机、对话期间冻结位移（C14）继续有效。

## 1. C15 聊天入口拆分与视觉统一

### R1 两条入口，互不干扰
- **点击宠物**：只浮出单行输入条，回车发送、Esc 关闭、回复期间输入条保持可用（回到 v1.7 及之前的交互，不新增任何面板）。
- **右键「历史对话…」**：打开只读历史查看器；重复点击可收起。启动、正常运行期间都**不自动显示**。

### R2 历史窗只读
查看器不得提供输入框与发送按钮，不得发消息；只能按天回看与切换日期。切到旧日期时，新产生的对话不得串进旧日期视图；切回当天时重新读全量，不丢消息。

### R3 会话状态不能因为大窗藏起来而消失
v1.8 把"思考中 / 正在回复 / 回复完成 / 出错了 + 大脑来源"放在大窗状态栏，现在大窗默认不可见，用户就又看不见了。因此**输入条顶部增加一行小状态标签**，与历史窗状态栏同步显示同一份状态；启动与保存配置后也立即显示当前大脑（大模型 / 本地小脑）。

### R4 视觉统一为扁平贴纸风
- 历史窗：无边框圆角卡片、自定义标题栏（标题 / 日期下拉 / 关闭按钮）、可拖动、Esc 关闭、气泡式消息（用户暖橘右对齐、助手奶油白左对齐、兜底淡粉）、每行带时间与来源、空态提示、底部注明本机保存位置。
- 输入条：同样圆角卡片 + 细描边 + 状态标签，去掉系统控件观感。
- 右键菜单：圆角、暖色 hover、分组分隔线。
- 配色沿用素材口径（奶油底 `#FFFDF7`、描边 `#DFC49A`、橘 `#E8A45C`、文字 `#3A2B21`），不引入渐变 / 阴影 / 贴图。

### R5 对话期间位移冻结的口径不变
输入条或历史窗任一开着都算"会话中"，宠物原地不动；两个都关掉才恢复。`THINKING`/`SPEAKING` 无论窗口开关都冻结（C14 继续生效）。

### 验收项
- AC-UI-1：点击宠物只出现单行输入条，历史窗不可见；启动后历史窗也不可见。
- AC-UI-2：右键「历史对话…」打开历史窗，重复点击收起；历史窗无输入行、无发送能力。
- AC-UI-3：发消息后输入条状态标签显示"思考中… · 大模型"（或本地小脑），错误时显示类别；历史窗打开时状态与之一致。
- AC-UI-4：切到旧日期后新消息不出现在该视图，切回当天可见。
- AC-UI-5：空历史显示引导文案，第一条消息到达时提示自动消失。
- AC-UI-6：历史窗可拖动、可点关闭按钮 / Esc 关闭，且不越出工作区。

## 2. 不作废的旧约束

- v1.8 C13 的按天保存格式 `~/.WisePet/chat/YYYY-MM-DD.json`、只追加不截断、损坏备份、完整回复落盘全部不变。
- v1.8 C13 的会话状态机与 `ChatStateChangedEvent` / `ChatTurnRecordedEvent` 不变，只是消费者从"一个大窗"变成"两个界面"。
- v1.8 C14 位移冻结不变；v1.6 C8 日志口径、v1.7 C12 睡眠回血不变。
- 用户输入原文仍明文落在本机，v1.8 R5 的隐私告知继续有效。

## 3. 范围外

- 多会话 tab 与会话重命名；会话 ID 仍是本地日期。
- 深色主题 / 主题切换（本期只统一到现有贴纸风）。
