# 桌面宠物 WisePet PRD v1.36

- 版本：v1.36
- 状态：已实现（待评审）
- 日期：2026-11
- 性质：增量需求（情感陪伴路线 A 五件事），不回改历史版本

## 0. 背景与动机

产品定位在「情感陪伴 vs 桌面助理」两条路线间选择，确定走 **A 情感陪伴**：核心是
「一个有记忆、会主动关心你的伙伴」，护城河是「长期记忆 + 主动性 + 稳定人格」。
本版落地该路线五件事，把已有的记忆/任务/提示词能力从「藏在命令面板里的功能」
变成「用户能感知到的陪伴」。

## 1. R1 记忆可见化（从命令面板搬到自然对话）

- 新增 `memory_visibility_line`：把长期事实转成 prompt 引导，让模型在话题自然相关时
  主动、克制地引用一次（「你之前说的XX，后来怎样了」），不炫技、不每次都提；
- 与 v1.31 `long_term_memory.prompt_line`（被问才答）互补：一个主动、一个被动；
- 新增 `name_first_line`：已知用户名字且首条消息时，鼓励自然叫一次名字，
  制造「它记得我」的第一下惊喜。

## 2. R2 新用户前 3 分钟（Aha moment）

- 首次引导第一步改为直接引导用户说出名字（「先告诉我你叫什么，我会一直记着」），
  把「它会记住你」这个最惊艳的能力前置到第一分钟；
- 复用既有「短陈述线索立即抽取」机制（v1.32 auto_facts）：说完一句就记住，
  三按钮/信号契约不变，CTAs 仍真实兑现。

## 3. R3 让宠物「活」起来（情绪 / 作息 / 小脾气）

- 新增 `mood_tone_line`：按 pet 心情/精力给语气指引（低落慢而软、疲惫轻而短、
  状态好活泼俏皮）；`Pet` 暴露只读 `vitals` 视图（不破坏 I3 写不变量）；
- 新增 `schedule_empathy_line`：深夜轻声、久别带想念、周一早晨打气；
- 新增 `sulk_line`：久不理 + 心情低时，指标关怀用「闹小脾气」话术替代普通问候
  （每天最多一次，仍走 QuietBudget）；
- 上述都注入系统提示词或复用 `_maybe_nudge` 出口，不新增推送通道。

## 4. R4 场景化的「替你操心」——页面盯梢

- 任务协议新增 `WATCH_PAGE` 类型：`parse_task_command` 识别「盯着 <url>，出现XX/有变化
  就告诉我」（URL 型优先于文件型判定）；
- `is_safe_watch_url` 静态白名单挡 SSRF（只 http(s)、拒 localhost/内网/元数据地址）；
- `page_changed` 纯函数判定：关键词出现或内容变化，首抓只记基线不出声；
- `TaskService` 注入 `page_fetcher` 回调（组装根用合并信任链 HTTP 抓纯文本，限长），
  关键词命中即停、纯变化监控持续盯；结果经 `SpeakRequestedEvent` 出境，照旧过打扰预算。

## 5. R5 可发现性革命（能力自然浮现）

- 新增 `discoverability_line`：按用户当前话语识别意图（累/怕忘/查信息/附近），
  提示模型顺势带出对应能力（休息提醒/记忆/联网搜索/周边），每次最多一条、不生硬推销；
- 替代「让用户去翻 20+ 命令面板命令」，能力在对话里长出来。

## 6. 验收项

| 组 | 验收 |
|---|---|
| AC-MEM-1 | 话题相关时模型主动、克制引用已记事实；首聊叫出名字；不炫技不重复 |
| AC-AHA-1 | 新手引导第一步引导说名字；说完即被记住，CTA 顺序与既有三步不变 |
| AC-MOOD-1 | 心情/精力/作息对应语气正确；闹脾气话术仅在久不理+低落时发，走 QuietBudget |
| AC-PAGE-1 | 「盯网页出现关键词/有变化」解析正确；SSRF 地址被拒；首抓不出声、变化/命中才提示 |
| AC-DISC-1 | 按话语意图顺势浮现能力，每次最多一条，无关话语不提示 |

## 7. 范围外

- 不做云账号/跨端同步（违背零上传定位）；
- 不做手机伴侣、皮肤在线商店（P3）；
- 页面盯梢不做 JS 渲染页/登录态页面（只抓静态文本，动态页可能无变化）；
- 记忆不主动画像、不猜测情绪（只用本机可观测事实）。
