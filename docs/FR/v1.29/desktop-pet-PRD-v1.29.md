# 桌面宠物 WisePet PRD v1.29

- 版本：v1.29
- 状态：已实现（待评审）
- 日期：2026-11
- 性质：增量需求（轴②「从会说话到可托付」A 类五项），不回改历史版本

## 0. 背景

`docs/产品规划.md` §8 结清了轴①（共处关系的持续性），并把轴②/轴③列为待做。
本版一次性交付上一轮规划中「A 类：高价值、零外部依赖、可立刻做」的全部五项。
共同底线：**零新增三方依赖、全部本机事实、不上传、不画像、不猜测情绪**；
所有新主动推送必须经唯一 `SpeakRequestedEvent` 出口并受打扰预算 / 免打扰 / 勿扰约束。

## 1. R1 助理任务队列（可托付）

- 用户可直接说：「盯着 D:/a.log，出现 ERROR 就告诉我」「每隔30分钟提醒我交周报」；
  本地正则解析成任务，不进 AI、不等模型（沿用快速通道口径）
- 任务跨重启存活（`tasks.json`）：`watch_file`（只读盯文件）/ `followup`（按间隔催）两类
- **失败重试**：读文件失败按 30s→60s→120s→240s→300s 退避；超过上限转为 `failed` 并
  用气泡如实说明，绝不静默消失
- **只读沙箱**：只接受用户显式给出的普通文件、拒符号链接、单文件 ≤512KB、
  只做子串匹配、不执行不写回
- **可消解 / 可取消**：用户说「搞定了」自动收尾 followup；命令面板「取消全部托付」
- 命令面板「我的托付」列出状态（进行中/已完成/已停止/已取消 + 已试次数）

## 2. R2 本地文档 RAG

- 用户显式指定一个本机文件夹 → 建倒排索引（BM25 近似，纯标准库，jieba 缺失用 bigram 降级）
- 白名单文本类型、单文件 ≤512KB、最多 300 文件 / 20MB / 2000 块；
  索引只落 `knowledge.json`，**默认关闭且目录为空**
- 聊天时按当前问题检索片段注入系统提示词（≤2200 字符，只在相关时引用）；
  无参的 `system_prompt_provider` 通过组装根缓存当前用户消息解决
- 保存设置时目录/开关变化自动重建；关掉即清索引，不残留用户文件片段

## 3. R3 事件驱动主动

- 从「按点找你」升级到「看情况找你」，只吃本机事实：系统空闲时长（非 Windows 降级）、
  系统时钟、今日完成专注次数
- 三条规则：久坐离开后回来、深夜仍在用电脑、连着完成多轮专注
- 按「规则 × 自然日」去重、每日总量封顶（默认 2 条），全部走打扰预算；
  规则可在设置里整体关闭。**不接天气/日历/联网 API**（与零依赖底线冲突）

## 4. R4 可遗忘时间线

- 命令面板「我记得你什么」从一句文本升级为**一页对话框**：聚合长期记忆事实、
  记忆变更、按天聊天记录、工具执行历史、托付、资料索引、埋点、惦记标记
- 勾选即**真正删除**（不是隐藏）：分派到各仓储的按条删除，删完 reload 内存态；
  支持导出清单到本机 Markdown
- 为此给 `ActionAuditStore` / `MemoryStore` 补按索引/按 key 删除能力

## 5. R5 惦记清单化

- 轴①原本只惦记「最近一条」，升级为多条清单（默认 3 条，可配 1~10）
- 已提过 / 已消解用指纹去重（`presence.json`），完成信号按**话题碎片**定向消解：
  「周报搞定了」只消解周报那件，不影响「整理笔记」那件；含糊的「搞定了」最多消解最新一条
- 提示词一次注入多条，但明确要求不要一口气全列出来；
  说「搞定了」时同时收尾 followup 托付（R1 与 R5 共用完成信号）

## 6. 总开关与隐私

- 设置 →「体验与隐私」新增 `助理能力` 总开关 + 7 项细项（不新增第 8 个分区）；
  「陪伴进阶」新增「惦记条数」
- 总开关一关，任务队列 / 资料注入 / 事件主动整体停用；资料索引单独有开关且默认关
- 新推送标题全部登记进 `PUSH_TITLES`

## 7. 验收项

| 组 | 验收 |
|---|---|
| AC-TASK-1 | 两类自然语言托付命中快速通道、落聊天记录、跨重启存活 |
| AC-TASK-2 | 文件命中关键词才开口；缺文件按退避重试、超限转 failed 并说明 |
| AC-TASK-3 | 「搞定了」消解 followup；可取消、可列出状态；只读沙箱拒绝符号链接/超上限 |
| AC-RAG-1 | 建索引/持久化/清空；检索命中并注入提示词，无命中不污染提示词 |
| AC-RAG-2 | 非白名单类型跳过、目录不存在报错可见；默认关闭时不读任何文件 |
| AC-EVENT-1 | 三条规则按事实触发、当日去重、每日封顶、平台降级不炸 |
| AC-FORGET-1 | 时间线聚合 8 类来源；勾选删除真的落盘，导出文本可读 |
| AC-RECALL-1 | 多条惦记并存、按指纹去重、完成信号按话题定向消解 |
| AC-CFG-1 | `AssistantSettings` roundtrip、非法值钳制、设置窗 `collect()` 不丢分节 |
| AC-PRIVACY-1 | 零新增依赖、新推送计入预算、全部数据落 `~/.WisePet/` |

## 8. 范围外（如实登记）

- 不做任意命令执行 / 写盘型托付（本版只读文件 + 提醒，写盘仍走既有三级权限）
- 不做向量库 / embedding（BM25 起步够用，零依赖）
- 不做屏幕内容 OCR / 联网事件源
- 自动更新、签名分发、插件市场仍属 B/C 类，见 `产品规划.md` §9
