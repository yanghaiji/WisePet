# 桌面宠物 WisePet 需求设计 v1.10

- **对应技术设计**：[NFR v1.11](../../NFR/v1.11/desktop-pet-tech-design-v1.11.md)
- **上一版本**：[v1.9](../v1.9/desktop-pet-PRD-v1.9.md)
- **状态**：待评审
- **变更性质**：增量修订（仅描述相对 v1.9 的变化），另补登两项已落地但未登记的需求

## 0. 背景

用户真机连跑两次后给出五点反馈，逐条实证/定位如下：

1. 「聊天记录没有真实存储吧，启动两次看不到上次，他也不记得我说了啥」——实证 `~/.WisePet/chat/2026-11-05.json` 确实生成、第二次启动历史窗也能读回，但 `ChatSession` 的 turns 为 0：记录只写盘/只显示，从未回灌给模型上下文。→ **C16（补登）**
2. 「聊天框挡住宠物，应该在宠物左侧，左侧没位置再放右侧」——旧定位用气泡锚点往下铺，压在宠物身上。→ **C17（补登）**
3. 「宠物移动位置后对话框不跟随过去」——浮窗只在打开那一刻算一次坐标，之后拖拽/走动都不再重算。→ **C18**
4. 「打开历史对话无法继续对话，应该可以继续对话，并把打开的单独对话框关闭」——历史窗被做成只读查看器，且右键打开时输入条仍留在屏幕上，两个入口叠在一起。→ **C19**
5. 「宠物回答的样式不好看，风格统一」——头顶回答气泡仍是白底 + 手绘尖角，与输入条/历史窗的圆角贴纸卡片割裂。→ **C20**

C16/C17 在上一轮已经代码落地（当时注释标 `FR v1.9 C16/C17`），但漏了文档登记；按「不回改历史版本」规约，本版本 §1 一并补登，代码注释统一改指 `FR v1.10`。FR v1.9 的 C15 拆分口径中「历史窗只读」这一条由 C19 替换，其余（入口拆分、状态标签、贴纸风、按天保存、冻结）继续有效。

## 1. C16 / C17 补登（已落地）

### R1 记录要真的被「记得」
启动时把最近若干天已落盘的 `user` / `assistant` 记录按时间正序回灌 `ChatSession`，跳过 `system` / 兜底话术；只灌内存，不发布事件、不重复写盘；`max_turns` 截断继续生效。输入条状态标签显示「已记 N 条（右键看历史）」，让保存是否生效一眼可见。

### R2 浮窗不压住宠物
聊天输入条与历史窗一律**左侧优先、左侧放不下放右侧**，垂直尽量与宠物居中，最后钳制进虚拟工作区；窄工作区下历史窗按较宽一侧收缩宽度。

### 验收项
- AC-MEM-1：第一次启动聊过的话，第二次启动后出现在发给模型的 messages 里。
- AC-MEM-2：恢复不会把旧记录再写一遍盘；磁盘条数不变。
- AC-DOCK-1：宠物在屏幕中间/左右边缘时，浮窗都不与宠物矩形重叠。
- AC-DOCK-2：两侧都放不下时历史窗自动收窄到可放，不越出工作区。

## 2. C18 聊天界面跟随宠物

### R1 位置变了就重贴
拖拽、自主走动、重力回落、分辨率变化后位置被钳制，只要宠物坐标真的改变，**当前可见**的聊天界面立即重新侧向停靠，保持左侧优先 / 右侧兜底。

### R2 跟随不得打扰正在进行的对话
跟随只改坐标：不重发激活信号、不抢焦点、不重读历史、不打断流式回复；隐藏的界面不参与重排。

### R3 用户手动摆的位置优先
历史窗仍可拖动；用户手动拖过之后不再被宠物位置拽回，直到下次重新打开（重新打开即恢复自动贴边）。

### 验收项
- AC-FOLLOW-1：打开输入条后把宠物拖到别处，输入条跟着贴到新位置的一侧。
- AC-FOLLOW-2：打开历史窗后移动宠物，历史窗跟着贴边且不压宠物。
- AC-FOLLOW-3：位置没变时不产生重排；窗口隐藏时不产生重排。
- AC-FOLLOW-4：手动拖过历史窗后，宠物再移动不会把窗口拽回。

## 3. C19 历史窗可继续对话、两个入口互斥

### R1 历史窗底部增加输入行
输入行 + 发送按钮，回车或点击都走同一个 `submitted`；空白消息丢弃、发送后清空并保持焦点，回复期间可继续输入。历史消息区本身仍只读。

### R2 打开历史窗时收起单独输入条
右键「历史对话…」打开历史窗时，把点宠物浮出的单行输入条关掉，屏幕上只留一个聊天界面；历史窗已开着时再点宠物，只把焦点给历史窗输入行，不再叠第二条输入条。

### R3 出口唯一、口径不变
两个界面的 `submitted` 都接到组装根同一条 `send_message`，会话状态、按天落盘、气泡回复、位移冻结（C14）全部沿用；`_chat_ui_active` 的合并判定保留作防御。

### R4 回看能力不受影响
按天切换、旧日期视图不串新消息、切回当天读全量、Esc / 关闭按钮 / 拖动关闭均不变。

### 验收项
- AC-CHATWIN-1：历史窗有输入行与发送按钮，回车和点击都能把消息送进 `ChatService`。
- AC-CHATWIN-2：先点宠物再右键历史，输入条消失、历史窗可见，会话仍处于冻结。
- AC-CHATWIN-3：历史窗开着时点宠物，不会弹出第二条输入条。
- AC-CHATWIN-4：空消息不产生任何请求；历史消息区仍不可编辑。
- AC-CHATWIN-5：从历史窗发出的消息仍按天落盘、状态同步、流式气泡照常。

## 4. C20 回答气泡风格统一

### R1 同一套贴纸卡片
去掉手绘尖角与旧配色（`#FFF8EA` / `#C9A876`），改用与输入条 / 历史窗同源的 QSS 圆角卡片：奶油底 `#FFFDF7`、描边 `#DFC49A`、文字 `#3A2B21`、橘点 `#E8A45C`、暖橘按钮 `#F8D79B`；不引入渐变 / 阴影 / 贴图。

### R2 行为不变
纯文本渲染、流式增量节流、按来源驻留时长、「知道啦」确认与自动消失全部保留；气泡上仍不标来源（v1.6 C8 口径）。

### 验收项
- AC-BUBBLE-1：回答气泡与两个聊天界面视觉一致，无三角尖角。
- AC-BUBBLE-2：流式逐段出字、到时自动消失、提醒确认按钮仍可用。
- AC-BUBBLE-3：气泡仍被钳制在工作区内，靠近屏幕边缘不越界。
