# 桌面宠物 WisePet 需求设计 v1.12

- **对应技术设计**：[NFR v1.13](../../NFR/v1.13/desktop-pet-tech-design-v1.13.md)
- **上一版本**：[v1.11](../v1.11/desktop-pet-PRD-v1.11.md)
- **状态**：待评审
- **变更性质**：增量修订（仅视觉，不改任何配置语义）

## 0. 背景

继聊天输入条 / 历史窗 / 回答气泡 / 托盘菜单统一为贴纸风后，用户真机指出**设置窗仍是原生 Qt 观感**：系统标题栏、`QGroupBox` 方框、方形原生输入框与按钮、状态文字用纯红 / 纯绿，和桌宠的奶油橘圆角卡片割裂。本版本只做视觉统一，配置字段、校验与保存链路一行不改。

## 1. C22 设置窗视觉统一

### R1 形态
无边框 + 透明背景的圆角卡片，自定义标题栏（橘点 + 「设置」+ `×` 关闭），标题区可拖动，Esc 与 `×` 都能关闭；不再出现系统标题栏。

### R2 分区与可滚动
四组系统 `QGroupBox` 换成 `QFrame#section` 小卡片（橘点 + 标题 + 表单）；内容放进 `QScrollArea`，窗口固定尺寸即可看全所有分区，小屏幕也不会撑出工作区。

### R3 控件配色同源
`QLineEdit` / `QPlainTextEdit` / `QSpinBox` / `QDoubleSpinBox` / `QComboBox` / `QCheckBox` / 滚动条全部 QSS 化，沿用奶油底 `#FFFDF7`、描边 `#DFC49A`、橘 `#E8A45C`、文字 `#3A2B21`、次级文字 `#9A7A55`，focus 时描边转橘；不引入渐变 / 阴影 / 贴图。

### R4 按钮与状态
保存 / 取消 / 测试连接按钮改贴纸风（暖橘主按钮 + 奶油次按钮），文案中文化；状态提示改成暖色胶囊，成功暖奶油、失败淡粉 `#F7E2E2`（与历史窗兜底气泡同色），不再是刺眼的纯红绿。

### R5 业务行为零改动
`api_key` 永不回显、留空即不修改、区间校验、测试连接、`on_saved` 回调、模态 `exec()` 与 `accept/reject` 结果全部保持；Save / Cancel 仍是 `QDialogButtonBox` 的标准角色。

### R6 坐标口径
无边框窗口的拖动与越界钳制继续走 `ui/screen_bounds.py`，不另取屏幕几何（规约 §2.6）。

### 验收项
- AC-SET-1：设置窗为无边框透明圆角卡片，标题栏有关闭按钮、可拖动、Esc 可关。
- AC-SET-2：四个分区都是贴纸小卡片且位于可滚动区域，窗口尺寸固定不撑出屏幕。
- AC-SET-3：所有输入控件与按钮的配色 / 圆角与聊天卡片一致。
- AC-SET-4：状态提示为圆角胶囊，错误态是淡粉而非纯红。
- AC-SET-5：原有设置窗测试（不回显 Key、留空不修改、区间校验、测试连接、保存 / 取消）全部照常通过。
- AC-SET-6：换肤、保存配置后热生效链路不受影响。

## 2. 不作废的旧约束
