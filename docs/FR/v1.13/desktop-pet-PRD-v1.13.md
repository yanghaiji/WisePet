# 桌面宠物 WisePet 需求设计 v1.13

- **对应技术设计**：[NFR v1.14](../../NFR/v1.14/desktop-pet-tech-design-v1.14.md)
- **上一版本**：[v1.12](../v1.12/desktop-pet-PRD-v1.12.md)
- **状态**：待评审
- **变更性质**：缺陷修订 + 视觉收尾（不改任何配置语义）

## 0. 用户反馈

两张真机截图指出三处残留问题：

1. 数值框右侧仍是**带竖线的原生方块上下箭头**（截图红框圈出 Temperature / 超时 / 走动速度 / 间隔等整列），与圆角输入框割裂。
2. 窗口底部常驻**一条空的米色横条**——那是没有内容的状态胶囊，看着像多余的空白块。
3. **「还不能移动这个设置窗口」**：v1.12 只把拖动过滤器装在标题文字与圆点两个 `QLabel` 上，标题栏是纯 `QHBoxLayout`（没有承载 widget），占绝大部分面积的空白处根本收不到事件。

## 1. C23 设置窗收尾

### R1 数值框箭头贴纸化
`QSpinBox` / `QDoubleSpinBox` 的 `::up-button` / `::down-button` 改成透明、无边框、圆角的小热区，hover 时才显暖色 `#F7E7CC`；保留系统绘制的小三角与上下微调、键盘输入、滚轮能力，输入区加右内边距避免文字压到按钮。**不新增任何图片 / qrc 资源**。

### R2 空状态不占位
状态胶囊初始隐藏，只有保存 / 测试连接 / 校验出结果时才 `show()`；不再有一条永远空白的米色横条。

### R3 整条标题栏都能拖
标题栏改为 `QFrame#titleBar` 容器，过滤器装在**容器 + 圆点 + 标题 + 卡片空白**上；关闭按钮不装，点击仍只关闭。坐标继续用 `globalPosition` 计算并由 `ScreenBounds.clamp()` 收进工作区。

### R4 初始位置合法
有 parent 的 `QDialog` 默认居中于右下角的宠物窗，可能一开始就落在工作区外，导致一拖就被 clamp 拽住。构造时显式摆到工作区上方中间，且默认高度 600 → 560，给小屏留出更多垂直移动空间。

### R5 可读性
表单标签由 `#9A7A55` 加深到 `#6B4F3A`，不改其它配色。

### R6 业务零改动
字段、校验、`api_key` 脱敏、`on_saved`、Save/Cancel 角色与全部既有行为不变。

### 验收项
- AC-SET-7：数值框不再出现带竖线的原生方块按钮，hover 有暖色反馈，鼠标 / 键盘 / 滚轮都还能改值。
- AC-SET-8：刚打开设置窗时看不到空状态条；出结果后胶囊出现且配色不变。
- AC-SET-9：按标题栏空白处 / 圆点 / 标题 / 卡片空白都能拖动窗口；`×` 点击不会误触发拖动。
- AC-SET-10：拖动不越出工作区；打开时窗口完整落在工作区内。
- AC-SET-11：v1.12 的 AC-SET-1~6 与既有 21 项设置窗测试全部继续通过。
