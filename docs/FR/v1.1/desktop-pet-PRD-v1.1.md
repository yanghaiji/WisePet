## 1. C1：宠物形象（修订 US-1、M1）

### 1.1 修订后的用户故事
作为用户，我希望桌面上是一只**看起来真的是猫/狗**的宠物，而不是一个几何占位图形，以便它像真宠物一样有存在感和生命力。

### 1.2 形象规格
| 项 | 约定 |
|----|------|
| 物种 | 橘猫（默认），后续皮肤可扩展 |
| 画风 | 扁平贴纸风：深色粗描边 + 平涂暖橘配色，无渐变阴影，小面积高饱和点缀 |
| 画布 | 单帧 256×256 透明底 PNG；UI 侧等比缩放居中绘制到 128×128 画布 |
| 状态覆盖 | 8 个动作，每个动作 4 帧循环：`idle / walk / sad / hurt / think / eat / speak / sleep`（共 32 帧） |
| 帧间一致性 | 同一动作内头位/耳位/尾巴相位连续变化，循环首尾可衔接，不出现跳帧感 |

### 1.3 验收标准（覆盖 v1.0 US-1 最后一条）
- Given 出厂仓库，When 应用启动，Then 宠物显示为橘猫序列帧动画，日志**不出现**素材缺失告警
- Given idle / walk / sad / hurt / think / eat / speak / sleep 八个动作，When 触发对应状态，Then 各自动画可切换且均为猫形（不混用占位圆脸）
- Given 用户删除或损坏任一素材目录，When 加载失败，Then 仍按 v1.0 规则回退程序绘制的占位形象并记录日志，不崩溃（**降级路径必须保留**）
- Given 素材帧尺寸不一致（非 256），When 渲染，Then 等比缩放居中，不裁切、不越界

### 1.4 边界
- 高分屏（Windows 125%/150% 缩放）下不得模糊到不可辨认
- 走动时允许左右翻转；翻转不得破坏描边连续性
- 动画不得引入新的运行期三方依赖（仍只依赖 PySide6）

## 2. C2：离线可聊（修订 US-3、M4）

### 2.1 修订后的用户故事
作为用户，我希望**装好就能对话**，不必先去找 API Key；等我愿意配置时，同一只宠物自然升级到真正的 AI 大脑。

### 2.2 对 v1.0 US-3 的替换
v1.0 US-3 第 3 条（未配置 Key / 断网 → 固定回复"我还没连上大脑哦"）**作废**，由本节 AC-LOCAL-* 替代。已配置 Key 但请求失败（401/429/5xx/超时/断网）时，仍保留 v1.0 的可读兜底话术与"沮丧"短动画——那是**故障**，不是**未配置**。

### 2.3 验收标准
| 编号 | Given / When / Then |
|------|---------------------|
| AC-LOCAL-1 | Given 未配置 api_key，When 用户发送任意消息，Then 宠物进入思考动画并以气泡回复一段与宠物人设一致的话术，回复正常结束（不卡在流式态） |
| AC-LOCAL-2 | Given 未配置 api_key，When 用户询问"你是谁/心情怎样/饿不饿/几点了"，Then 回复内容取自宠物**当前**的饥饿/心情/精力/系统时段，而非固定文案 |
| AC-LOCAL-3 | Given 未配置 api_key，When 用户发送未命中任何话题的消息，Then 走反射式兜底（复述用户片段 + 引导），**不得**出现"我还没连上大脑哦" |
| AC-LOCAL-4 | Given 未配置 api_key，When 会话首次回复，Then 附带一句能力说明（如何在设置里接上 AI）；后续回复不再重复该说明 |
| AC-LOCAL-5 | Given 未配置 api_key，When 同类话题连续追问，Then 回复轮换且不与上一条重复，且同一输入序列的回复**可复现**（不依赖随机数） |
| AC-LOCAL-6 | Given 未配置 api_key，When 本地回复产生，Then 该回复计入会话历史（下一轮上下文可见），并同样走拟流式逐段上屏 |
| AC-LOCAL-7 | Given 已配置 api_key，When 发送消息，Then 仍走 AI 网关流式，本地小脑**完全不介入** |
| AC-LOCAL-8 | Given 用户清空会话，When 再次发言，Then 首次能力说明重新出现（回复状态与会话一起重置） |

### 2.4 边界与业务规则
- 本地回复是纯计算、瞬时完成：不得引入网络/线程依赖，不得阻塞 UI 线程
- 本地模式只**读取**宠物状态，不得修改饥饿/心情/精力（不产生副作用）
- 话题覆盖下限：问候、身份、状态感受、食物、睡眠、夸奖、冒犯、亲近、玩笑、时间、天气、功能帮助、提醒、AI 配置指引、致谢、告别，共 16 类 + 兜底
- 中文关键词直接子串匹配；英文短词（`hi`、`ai` 等）必须带尾空格，避免误命中 `this` / `again`
- 时间类回复只给"时段 + 整点"的模糊表述，不得伪装成精确时钟或天气服务

### 2.5 对其它模块的影响
- M7 配置：api_key 为空不再是功能缺失。设置窗口必须向用户说明“留空也能聊（本地小脑），填上 Key 会更聪明”：API Key 为空时的输入框占位文案、以及保存后的状态提示均已按此修正（v1.1 增量实现）
- 成功指标（A 章）：「聊天首字响应」在本地模式下为纯本地耗时，远低于 100ms 目标
