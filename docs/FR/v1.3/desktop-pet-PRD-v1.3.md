## 1. C4：画风改为 Q 版可爱（替换并作废 v1.2 §2）

### 1.1 判定依据
桌宠常驻尺寸是 128×128 画布，用户在这个尺寸上能接收的信息只有**剪影、比例、眼神**三件事。写实厚涂依赖的毛流纹理、瞳孔结构、多层明暗在该尺寸下全部退化为噪点，反而不如符号化的 Q 版读得清。故本版明确：**可爱度优先于结构准确度**。

### 1.2 形象规格（替换 v1.2 §2.2）
| 维度 | v1.2（结构写实，作废） | v1.3（Q 版可爱） |
|------|------------------------|------------------|
| 头身比 | 约 1:1.5，颅顶/口吻/颊部/臀腿分段 | 大头（头半径 ≈ 画布 22%），身体小而圆，四肢不建模，只留两只前爪交代"手短" |
| 轮廓 | 取消描边，靠边缘压深 | 同色系细描边（约 4.6px），保证小尺寸剪影干净 |
| 上色 | 径向 + 线性 + 反光三层 | 单层柔和渐变 + 左上高光，低饱和奶油配色 |
| 毛发 | 沿剪影法线密排毛流 + 内部明暗纹理 | 只在脸颊两侧与尾尖留少量软簇；**整圈毛边禁止**（小尺寸糊成太阳花） |
| 眼睛 | 真实眼裂 + limbal ring + 猫科竖瞳 + 眼睑投影 | 大圆眼（占脸约 30%）+ 虹膜暖芯 + 双高光；情绪靠眼形变化（下垂/弯月/闭眼/`><`），**不画写实眼裂与竖瞳** |
| 嘴 | 皮革质感鼻镜 + 转机软线 | 迷你三角鼻 + ω 形小嘴 + 腮红 |
| 尾巴 | 由根到尖的锥形，带环纹 | 同样收细，但**贴地拖出体侧、尾尖轻翘**；环纹取消（分节观感） |
| 落地 | 接触阴影 | 保留接触阴影 |

### 1.3 三皮肤的区分优先级
必须按 **剪影 > 花纹 > 配色** 的顺序区分，不得只靠颜色：
| 皮肤 | 剪影 | 花纹 | 配色 |
|------|------|------|------|
| 橘猫 `cat` | 立三角耳、蓬松尾贴地 | 额头虎斑 + 体侧浅色围裙 | 橘色 |
| 柴犬 `dog` | 宽而短的立耳、尾巴上抽更明显 | 无虎斑 | 奶白偏沙（深色鼻头） |
| 小猴 `monkey` | 圆侧耳（贴在头两侧）、细长尾高翘 | 无虎斑、无胸口浅块 | 棕灰 |

### 1.4 验收标准
- Given 三套皮肤，When 生成素材，Then 每套 8 动作 × 4 帧共 32 帧、合计 96 帧全部落盘且可解码
- Given 任一帧在 128×128 画布渲染，When 目检，Then 不得出现毛流噪点、脏色块、断开的悬空部件（尾巴/食盆必须与身体有明确连接）
- Given 三皮肤并排目检，When 遮住颜色只看剪影，Then 仍能分辨物种
- Given 同一动作 4 帧，When 连续播放，Then 除呼吸/眨眼/摆尾相位外逐像素可复现（随机数以皮肤+动作+帧号为种子）
- Given 8 个动作，When 逐行目检，Then 情绪可读：开心=弯月眼+张嘴、难过=下垂眼+泪滴、疼=`><`+皱眉、思考=汗滴、睡觉=闭眼+Z

### 1.5 边界
- 单帧仍为 256×256 透明 PNG，仍由 `tools/gen_pet_assets.py` 程序化生成，不引入外部素材与网络下载
- 画风改动只发生在离线生成脚本，运行期管线与依赖零变化

## 2. C5：兜底话术卫生（修订 v1.2 §3.5、新增 AC-LOCAL-4）

### 2.1 现象
本地小脑的兜底会把"上一轮记下的话题"回显成本轮听到的内容，而寒暄轮（"你好""谢谢""再见"）也被记成话题，于是出现"用户说你好 → 用户输入乱码 → 回复『我听到的是「你好」』"。

### 2.2 规则
| 编号 | 规则 |
|------|------|
| R1 | 寒暄类意图（问候/致谢/道别/自报身份/夸赞/辱骂/示爱/求助/提醒/问 AI）**一律不记录话题** |
| R2 | 兜底引用上一轮话题的前提是本轮文本是**回指**（"嗯""然后呢""还有呢""所以呢"这类），否则只能回显本轮原文 |
| R3 | 回显原文为空时必须降级为通用引导语，不得输出空引号 |

### 2.3 验收标准
| 编号 | Given / When / Then |
|------|---------------------|
| AC-LOCAL-4a | Given 用户说过"你好"，When 再输入一句无主题词的乱码，Then 回复回显**本轮**原文，不得出现"我听到的是「你好」" |
| AC-LOCAL-4b | Given 用户说过"我在写代码"，When 只回"嗯"，Then 回复仍引用"代码"这一话题（回指路径不得被 R1/R2 误伤） |
| AC-LOCAL-4c | Given 会话内没有任何话题记录，When 触发兜底，Then 输出通用引导语，不出现空引号 |
