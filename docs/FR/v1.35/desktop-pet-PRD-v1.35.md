# 桌面宠物 WisePet PRD v1.35

- 版本：v1.35
- 状态：已实现（待评审）
- 日期：2026-11
- 性质：增量需求（天气能力完整化 + 定位精度改善 + 贴纸风弹窗 + 工具准入修正），不回改历史版本

## 0. 背景与动机

v1.34 收口三件后，真机连续多轮反馈暴露四个问题，本版逐一修正：

1. **工具被误禁**：v1.34 R3 的「lite 档禁工具循环」把 glm-4-flash 的 `get_location`/`nearby_pois` 全废了，模型只能回答「我查不到」——而它本就是 v1.30/v1.33 联网工具的驱动模型；
2. **天气只做了一半**：v1.34 只做了主动推送，聊天问天气没有工具，且 Open-Meteo 的 forecast 端点在本机网络下 SSL 握手超时；
3. **定位太粗**：系统精确定位超时回落 IP 城市级中心点，「附近」搜出来的店离实际位置远；
4. **弹窗样式不统一**：位置授权仍用系统 `QMessageBox`，与全项目贴纸风格割裂；
5. 用户追加诉求：天气回答要带时间/气温/湿度且有格式；主动天气提示要像喝水/久坐一样**可配间隔**。

## 1. R1 工具准入修正（修正 v1.34 R3）

- **撤回按模型档位禁用工具**：`tools_allowed` 只看「工具调用」总开关，不再按 lite 档剥夺工具。防编造靠提示词约束 + 工具结果注入，不靠「不给工具」；
- 能力提示语气从「没工具就说查不到」改为「先调工具拿真实结果，不许凭记忆编造店名/温度/数字」；
- 工具能力声明不再被「联网搜索」单开关一刀切关掉（只看工具调用总开关）；
- 埋点 `feat:tier_lite_blocked` 随拦截取消而停止产生。

## 2. R2 天气能力完整化

### 2.1 聊天天气工具 `get_weather`
- agent 新增 `get_weather` 工具（用户主动问天气/冷不冷/带不带伞时调用），即时查实况，不受「主动天气播报」开关影响；
- 工具结果是一段**已排版的 markdown 卡片**（标题 + 加粗列表 + 引用），含天气/气温/今日温度范围/湿度/风力/查询时间/观测时间/提示；
- **格式兜底**：弱模型常把卡片揉成一段话（真机实证），由 `agent_loop` 检测「调用过 get_weather 且回复丢了 markdown 符号」时用工具原始卡片替换，保证格式一定落到气泡。

### 2.2 双源天气网关（实测修正）
- 主源 `t.weather.itboy.net`（中国天气网数据，国内 CDN，免 Key、~0.5s 稳通）：内置约 40 个主要城市代码表按城市名匹配；
- 备源 Open-Meteo（geocoding → forecast）：未收录城市兜底；
- 实测本机网络：Open-Meteo 的 forecast 端点 http/https 均超时，wttr.in 自签证书验证失败，国内源稳定可用——故国内源优先；
- 城市代码未收录的县城/小城市回落备源；两源都失败返回 None 静默跳过，不阻塞主流程。

### 2.3 主动天气播报改为「每隔 N 分钟」
- 撤回 v1.34 的「固定时刻 + 受情境额度限制」方案：天气原本是情境候选，和回来/深夜/鼓励共用每天 2 条额度，很容易被挤掉根本看不到；
- 改为像喝水/久坐一样**按间隔定时**（`interval_min`，30~1440 分钟，默认 180），首次立即报、之后每满间隔报一次、跨日重置，坏天气额外提醒每天最多一次；
- 独立来源 `weather` 不占情境额度，仍统一走 `QuietBudget` 与情境评分（勿扰/深夜/专注不打扰）；
- 播报文案用简短宠物口语（非 markdown 卡片），与喝水/久坐一致；
- 旧固定时刻配置升级后折算成「每 24 小时一次」，不失效。

## 3. R3 定位精度改善

- 新增命令面板「定位诊断」：显示当前定位来源（系统精确 / IP 城市级）、坐标、系统定位源可用性、高德 Key 状态，并给出精确化指引；
- 新增区域名地理编码：用户问「附近」带区域名（如「桂林路 咖啡」）时，系统精确定位不可用时先用区域名地理编码到街道级中心点，替代误差几公里的 IP 城市中心（需高德 Key）；
- 如实登记边界：IP 定位物理上只到城市级；系统精确定位需 Windows 位置服务开启（应用无法代开），基础设施（QtPositioning + winrt 源）已验证可用。

## 4. R4 贴纸风三选一弹窗

- 新增 `ChoiceDialog`（贴纸风三选一，复用 InputDialog 配色），位置授权弹窗从系统 `QMessageBox` 换成它，视觉与全项目统一；
- 三个选项（仅本次允许 / 总是允许 / 拒绝）与持久化行为不变。

## 5. 验收项

| 组 | 验收 |
|---|---|
| AC-TOOLS-1 | glm-4-flash 等 lite 档模型可正常调用 get_location/nearby_pois，不再回答「我查不到」；总开关关闭才禁用工具 |
| AC-WEATHER-1 | 聊天问天气触发 get_weather，回复含 markdown 卡片（标题/加粗列表/查询时间/气温/湿度）；弱模型揉成一段时兜底恢复格式 |
| AC-WEATHER-2 | 国内源优先取到真实天气；两源都失败时静默跳过不崩；冷门城市回落备源 |
| AC-BROADCAST-1 | 开启主动播报后首次立即报、按间隔再报、跨日重置；坏天气额外提醒每天一次；不占情境额度、走 QuietBudget |
| AC-LOCATE-1 | 「定位诊断」显示来源/坐标/系统定位源/高德 Key；带区域名的「附近」用区域名精确定位 |
| AC-UI-1 | 位置授权弹窗为贴纸风三选一，与设置窗同配色，三个选项行为不变 |

## 6. 范围外

- 不代用户开启 Windows 位置服务（系统级权限，只能指引）；
- 不做天气历史/预报多日曲线（只做实况 + 今日温度范围）；
- 不做embedding向量库、云账号、多端同步；
- 本版不引入新的运行时三方依赖。
