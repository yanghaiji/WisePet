## 1. C38：从「功能能用」到「价值被兑现」

用户路线图评审后的结论：本项目 21 份 FR 里连续 7 版是缺陷修订 / UI 返工，缺的不是功能，
而是激活、留存与「敢用」的闭环。本版一次性交付 P1（把核心爽点做深）与 P2（从会聊天到替你记住）。

| 编号 | 需求 | 验收项 |
|---|---|---|
| R1 | **首次价值时刻**：首次启动给出三步贴纸引导，每步 CTA 必须真的兑现一次价值（打开输入条 / 排一条 1 分钟提醒），不是只翻页 | AC-FIRST-1~3：三步顺序与文案、CTA 发信号、完成写一次性标记、右键可重看、非首次不自动弹 |
| R2 | **行为因果驱动**：自主行为按本机可观测的「时段 / 专注中 / 勿扰」选择，而不是纯随机轮播 | AC-CAUSE-1~3：专注或勿扰时原地安静、清晨伸懒腰、夜间去睡；不破坏全状态轮播覆盖；设置可关闭 |
| R3 | **成长兑现外观**：等级 ≥4 起，宠物外观要有可见差异 | AC-GROW-1~2：三档缩放递增 + 等级徽章；关掉成长体系时不叠加；不新增素材文件 |
| R4 | **打扰预算一等公民**：主动推送有每日总量与单来源上限，支持一键免打扰 | AC-QUIET-1~4：超额拦截、按自然日重置、一键全停、**用户主动发起的回复与工具反馈必达**、额度与开关进设置 |
| R5 | **本地长期记忆与跨日检索**：记住用户主动说过的名字 / 近况 / 项目名，重启仍认得；聊天记录可跨日全文检索 | AC-MEM-1~5：抽取与落盘、注入系统提示词、回填本地小脑、大小写不敏感与条数上限、一键关闭、搜索态不被新消息冲掉 |
| R6 | **场景包取代功能堆砌**：把番茄钟 / 提醒 / 新闻 / 周报 / 预算组合成 2~3 个可一键启用的场景 | AC-SCENE-1~3：三套预设各有差异化配置、一键落盘热生效、**绝不改动 api_key / 人设 / 位移参数**、未知 id 原样返回 |
| R7 | **意图协议「敢用」门槛**：写盘类操作从「一句标题 + 折叠详情」升级为完整预览 + 权限分级 + 可撤销 | AC-ACT-1~5：三级权限（auto/confirm/deny）全覆盖、预览含目标路径与将写入正文、可选「以后都允许」且受设置约束、写前快照、撤销还原或删除新文件 |

## 2. 边界与已知取舍

- **不改状态机白名单、不改 `SpeakRequestedEvent` / `ChatTurnRecordedEvent` 契约**；预算判定放在唯一发布口 `_on_speak`，靠 `source` 白名单 + `title` 兜底识别主动推送。
- **不改素材文件**：成长外观只在 `PetWindow` 绘制层叠加（用户曾为 4 张图返工 4 轮，素材生产是已知瓶颈）。
- **不引入新外部依赖**：天气 / 日程驱动以本机可观测的时段、专注状态、勿扰时段代替；长期记忆全部只落 `~/.WisePet/`，不上传。
- **撤销只保留最近一次**：进程重启后清空；原文件读不出来时拒绝撤销，避免误删。
- **引导只在真实入口判定**：组装测试构造 `PetApplication` 时默认不弹，避免 offscreen 挂死。

## 3. 范围外（明确不做）

自动更新 / 代码签名公证 / 产品埋点（P0）、皮肤工坊 / 插件系统 / STT / 手机伴侣（P3），
以及让天气或日程 API 进入运行时依赖。理由见 [产品规划 §5](../../产品规划.md)。
