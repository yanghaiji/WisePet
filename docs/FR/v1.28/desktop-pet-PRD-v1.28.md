# 桌面宠物 WisePet PRD v1.28

- 版本：v1.28
- 状态：已实现（待评审）
- 日期：2026-11
- 性质：增量需求（陪伴轴①「从一直在，到一直记得」），不回改历史版本

## 0. 背景与定位

`docs/产品规划.md` §0 把产品核心定义为「共处关系」＝持续性 × 主动性 × 本地可信。
轴①是「持续性」的纵深：现有实现只做到「它一直在」，缺「它一直记得、你们的关系是双向的」。
本版补齐四项，全部基于**本机可观测事实**（聊天记录时间戳、系统时钟、专注/勿扰状态），
零联网、零画像、零新增第三方依赖，守住「本地数据不上传」底线。

## 1. C46 陪伴关系四项

### R1 主动引用（惦记）

- 从近 N 天的**用户**聊天记录里挑一条「还没兑现的惦记」（明天/回头/打算/准备/还没…），
  排除命令句（提醒我 / 帮我写 / 专注 / 番茄钟）与太短太长的句子；
- 刚说完（<1 天）不惦记；之后出现过「完成了/搞定了/交了」等信号即视为已兑现；
- 命中后：① 注入系统提示词，让模型在话题自然相关时轻轻提起；② 启动 3 分钟后、
  当天首次，用「我还记得」标题推一条气泡（走打扰预算，不再单独刷屏）；
- **隐私分界**：「主动推送」与「只让 AI 知道」是两个独立开关，可只关前者。

### R2 情境化的时间与状态

- 行为侧在既有 `context_driven`（专注/勿扰/深夜/清晨）之上，补
  「周一早晨」→ 精神小跑、「刚结束一场专注」→ 伸懒腰、「深夜」→ 去睡；
- 话术侧把同一事实注入系统提示词（「此刻情境：周一早晨」等），模型说话贴合当下；
- 关闭「情境化」时新字段传未知值，行为与旧版逐字节一致。

### R3 可干预的共处

- 「摸一下」不再只加心情值/放固定动画，而是**真的打断当下自主行为**（走/跑/睡）
  并给一个可见的回应状态（伸懒腰蹭回来）；
- 新增「叫一声小墨」（命令面板）：打断当下动作 → 抬头看你（SPEAKING）+ 应一声；
- 拖拽中、AI 思考/说话时不打断（手在拖、或在等回复）。

### R4 久别重逢

- 用精确时间戳记录「上次出现」，抢在启动流程覆盖前读取；离开超过阈值
  （默认 20 小时，可配）时，开机问候改为本地确定的「好久不见」文案，
  按离开时长分档；未配 AI / AI 超时也必定说得出，不等模型；
- 久别事实同时注入系统提示词，后续对话不会把「好久不见」当成无中生有。

### R5 一个总开关，可直接退回旧行为

- 设置 →「陪伴进阶」新增 7 项关系感控件；总开关一关，四项整体停用；
- 所有新主动推送必须计入 `PUSH_SOURCES/PUSH_TITLES`，照旧受打扰预算 / 免打扰 / 勿扰约束。

### R6 可查询

- 命令面板「我还记得什么」随时查看当前惦记（用户主动发起，走必达旁路，不占预算）。

## 2. 验收项

| 组 | 验收 |
|---|---|
| AC-RECALL-1 | 命中未兑现惦记并注入提示词；命令句、太新的话、已完成的惦记一律不命中 |
| AC-RECALL-2 | 启动 3 分钟后推一条「我还记得」，当天不重复；关推送/总开关即不推 |
| AC-RECALL-3 | 只关「主动惦记」时，AI 仍可自然提起（提示词开关独立） |
| AC-CONTEXT-1 | 周一早晨→小跑、刚结束专注→伸懒腰、深夜→睡；旧 `context_driven` 用例零回归 |
| AC-CONTEXT-2 | 系统提示词含情境短语；关情境化后 `BehaviorContext.weekday=-1`，旧行为不变 |
| AC-INTERACT-1 | 走动中摸一下→伸懒腰；睡觉中叫一声→SPEAKING 并应声；锁定态不打断 |
| AC-REUNION-1 | 首次安装不装久别；间隔按 24h/36h/72h 分档；阈值可配 |
| AC-REUNION-2 | 久别时开机问候为本地文案，AI 未配置/超时也必达 |
| AC-CFG-1 | 新配置分节 roundtrip 不丢、非法值回落默认；设置窗 `collect()` 透传该分节 |
| AC-PRIVACY-1 | 全部数据落在 `~/.WisePet/`，不上传；新推送计入打扰预算 |

## 3. 范围外（如实登记）

- 不猜测情绪、不做用户画像、不接天气/日历等外部 API；
- 不新增 `BehaviorState`（避免动状态机白名单与动画素材映射）；
- 「主动引用」不做 AI 润色：惦记是确定事实，本地文案秒出且不依赖网络，
  AI 只负责在对话里接得自然（R1 的提示词注入）；
- 助理任务队列 / 失败重试 / 沙箱、本地文档 RAG 属轴②，不在本版。
