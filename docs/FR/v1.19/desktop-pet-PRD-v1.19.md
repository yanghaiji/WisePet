# 桌面宠物 WisePet 需求设计 v1.19

- **对应技术设计**：[NFR v1.20](../../NFR/v1.20/desktop-pet-tech-design-v1.20.md)
- **上一版本**：[v1.18](../v1.18/desktop-pet-PRD-v1.18.md)
- **状态**：已实现（待评审）
- **变更性质**：陪伴进阶四项（对应产品规划 v2.0 通知中心 / v2.2 TTS·回忆录·成长体系）

## 0. 背景

产品规划 v2.2「陪伴」线的四个承诺——**会说话、少打扰、有记忆、能长大**——此前只停在纸面。本版一次性把它们落地，并全部收进设置窗新增的第五个分区 **「陪伴进阶」**。四项默认取向保守：会打扰人的（语音、系统通知）默认关，只做记录不打扰的（周报、成长）默认开。

---

## 1. C30 语音说话（TTS）

### R1 关键事件可开口朗读
提醒、AI 回复、每周回忆录、成长升级等「宠物说话」的时刻，若开启语音则**用本地 TTS 朗读出来**；未开启时零副作用（静默，等同现状）。

### R2 跨平台、免安装、零上传
Windows 用系统自带 `System.Speech`、macOS 用 `say`，**不装第三方、不联网、文本不出本机**；其它平台静默不支持。

### R3 朗读前剔除表情符号
只读**文字**，表情包（emoji/装饰符号）一律不念；纯 emoji 的消息**不触发朗读**，避免对着乱码或空停顿念。

### R4 音量 / 语速 / 开关进设置
「陪伴进阶」分区提供：语音说话开关、朗读音量（0~100%）、语速（-10~10）。默认**关闭**。

### R5 尽力而为，绝不带崩
语音引擎缺失、调用失败、超时都静默降级，不影响气泡/聊天等主流程。

### 验收项
- AC-TTS-1：开启后提醒/AI 回复触发朗读；关闭时不念且无异常。
- AC-TTS-2：Windows 走 `System.Speech`、macOS 走 `say`，其它平台 no-op。
- AC-TTS-3：含 emoji 的句子只念文字；纯 emoji 不念。
- AC-TTS-4：音量/语速设置保存即生效，非法值钳到范围。
- AC-TTS-5：朗读在后台线程，UI 不卡。

## 2. C31 通知接入系统通知中心（可选）

### R1 打扰方式二选一
提供「系统通知」开关：开启后提醒/新闻/鼓励等通知**接入 Windows 通知中心 / macOS 通知中心**（经托盘图标下发）；关闭则维持现有**宠物头顶自绘气泡**。

### R2 自绘气泡仍是默认
默认 `use_system=False`，保持陪伴感；系统通知是给「通知疲劳」用户的可选减压阀。

### R3 必达兜底
系统托盘不可用的环境自动**回退自绘气泡**，通知不丢。

### R4 取舍如实登记
走系统通知后，提醒**不再携带「知道啦」确认按钮**（系统 toast 不做自定义按钮），确认语义由「下次间隔重排」兼顾。此为已知取舍。

### 验收项
- AC-NOTIFY-1：开启系统通知后提醒进通知中心、不再压头顶气泡。
- AC-NOTIFY-2：关闭时行为与旧版完全一致（气泡 +「知道啦」）。
- AC-NOTIFY-3：托盘不可用时回退气泡、通知必达。

## 3. C32 回忆录 / 每周周报

### R1 每周定时推送
在指定「推送日 + 推送时刻」（默认**周日 20:00**）基于**最近 7 天本地聊天记录**生成一条周报，如「本周我们聊了 N 句，你问最多的是「XX」…」。

### R2 有 AI 润色、无 AI 也能出
配了模型 Key 时用 AI 把数据润色成宠物口吻；未配 Key 或失败时回落**本地模板文案**，周报照样发得出。

### R3 一周只推一次
按自然周（ISO 周号）去重：同一周推过就不再推，重启也不重推；错过推送日不补推。

### R4 勿扰顺延
落在勿扰时段内则顺延到时段结束后再推（复用既有顺延通道）。

### R5 数据全本地
只读本机按天聊天记录，不上传、不联网取数。

### 验收项
- AC-WEEKLY-1：到「推送日+时刻」推送一次，同周不重复。
- AC-WEEKLY-2：无 AI Key 时走本地文案仍出周报。
- AC-WEEKLY-3：周报在勿扰时段顺延。
- AC-WEEKLY-4：聊天数据全本地读取。

## 4. C33 成长体系（等级 / 形态）

### R1 互动积累积分
**喂食 +2、抚摸 +1、聊天 +1、每陪伴一个新自然日 +10**，累计成长积分并本地持久化（`growth.json`）。

### R2 积分→等级→形态
积分换算等级（逐级递增门槛），等级映射三种**形态**：`幼年期 → 成长期 → 成熟期`（Lv4 进成长期、Lv10 进成熟期）。

### R3 升级有反馈
升级或换形态瞬间，宠物冒一句成长播报（复用气泡通道）；「陪伴统计」面板底部显示 `成长：LvX · 形态`。

### R4 可关闭、向后兼容
「陪伴进阶」分区提供成长体系开关（默认开）。关闭时不再累加，历史数据保留。

### 验收项
- AC-GROWTH-1：喂食/抚摸/聊天/跨日按分值累加。
- AC-GROWTH-2：积分达门槛升级、跨形态，播报一次。
- AC-GROWTH-3：统计面板显示当前等级与形态。
- AC-GROWTH-4：数据落 `growth.json`，重启不丢；关闭后停止累加。

## 5. 附带体验修正

- **设置窗加宽**（520→640、最小宽 460→560）：新增「陪伴进阶」分区后长标签（如「聊天框空闲隐藏」）不再被截断，免去左右挪动。

## 6. 已知不足（指向后续 v2.4，本版如实登记不粉饰）

- **成长形态尚未改变外观**：目前 `形态` 只体现在统计面板文字，宠物动画/皮肤不随成长变化——「小猫→成猫」的视觉承诺未兑现，是最大落差。
- **成长只增不减、无「想你」**：掉线久了不会想念、不掉分，缺情感张力与召回钩子。
- **TTS 无播放队列 / 音色选择**：提醒+回复+升级并发触发可能叠音；未提供音色下拉。
- **周报话题依赖词频**：近 7 天聊得很少时 `top_topic` 可能为空（0 条消息已有「安静待在一起」兜底文案，但少量闲聊仍偏干），可考虑更丰富的情感化统计维度。

## 7. 不作废的旧约束

- 通知统一驻留、勿扰顺延、按天记录、气泡风格、多模型方案、本地小脑全部不变。
- 四项均为**新增旁路能力**：任一关闭或环境不支持时，行为回落到 v1.18 之前，不影响既有链路。
