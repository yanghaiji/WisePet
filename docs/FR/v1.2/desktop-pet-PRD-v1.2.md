# 桌面宠物 AI Bot 需求规格说明书（PRD）

- **版本**：v1.2
- **状态**：待评审
- **上一版本**：[v1.1](../v1.1/desktop-pet-PRD-v1.1.md)
- **技术约束**：Python + PySide6，跨平台（macOS / Windows）；离线小脑允许引入**纯统计**分词库（惰性加载、可缺失回退），不得引入生成式模型
- **交付形态**：源码 + 一键运行脚本（打包发布留待后续版本）

> 本版为**增量修订**，只描述相对 v1.1 的变化；未提及的章节一律沿用 v1.1 与 v1.0，不重复抄写。v1.1 §1.2 的「画风」一行由本版 §2.2 替换，其余形象规格继续有效。

## 1. C1：多皮肤（修订 US-1、M1、M7）

### 1.1 用户故事
作为用户，我希望能在设置里挑一只**我自己想要的动物**（猫 / 狗 / 猴），挑完立刻在桌面上看到它，以便这只宠物是"我的"，而不是出厂给我哪只算哪只。

### 1.2 皮肤规格
| 项 | 约定 |
|----|------|
| 皮肤集合 | `cat`（橘猫，默认）、`dog`（柴犬）、`monkey`（小猴），共 3 套 |
| 素材目录 | `assets/pet/{skin}/{action}/01..04.png`，每套 8 动作 × 4 帧 = 32 帧 |
| 配置项 | `AppConfig.pet.skin`，字符串，取值范围同上；非法值按默认皮肤处理并可被保存修正 |
| 可用性判定 | 只有 8 个动作目录全部齐帧的皮肤才算"已安装"，设置窗口只列出已安装皮肤 |
| 缺帧回落 | 请求的皮肤缺某动作时，回落默认皮肤的同名动作；默认皮肤也缺才走 v1.0 占位降级 |
| 切换生效 | 保存后**不重启**即时生效：立即换帧加载器并强制重取当前动作的帧 |

### 1.3 验收标准
| 编号 | Given / When / Then |
|------|---------------------|
| AC-SKIN-1 | Given 出厂仓库，When 打开设置窗口，Then 皮肤下拉框出现"橘猫 / 柴犬 / 小猴"三项且默认选中橘猫 |
| AC-SKIN-2 | Given 当前为橘猫，When 选择小猴并保存，Then 桌面宠物在**不重启**的前提下立即变为小猴，且当前动作连续播放不卡帧 |
| AC-SKIN-3 | Given 用户手工删除 `assets/pet/dog/walk/`，When 加载该皮肤该动作，Then 回落默认猫的 walk 帧并记录一条告警，程序不崩溃 |
| AC-SKIN-4 | Given 某皮肤 8 动作不齐，When 打开设置窗口，Then 该皮肤不出现在下拉选项中（不得让用户选到一个坏皮肤） |
| AC-SKIN-5 | Given 配置文件被写入 `skin="dragon"`，When 应用启动，Then 按默认皮肤渲染且配置归一，不出现异常弹窗 |
| AC-SKIN-6 | Given 切换皮肤，When 观察宠物说话气泡与本地回复，Then 自称随皮肤变化（小猫 / 小狗 / 小猴），语气词同步（喵 / 汪 / 叽） |

### 1.4 边界
- 皮肤切换只影响外观与自称，**不得**改变状态机、提醒、聊天等任何业务行为
- 新增皮肤不得要求改动运行时管线（loader / animator / UI 契约保持稳定）

## 2. C2：画风升级为结构写实（替换 v1.1 §1.2「画风」行）

### 2.1 目标与诚实预期
用户诉求是"真实的小猫、小狗、小猴的感觉"。本版交付的是**厚涂插画 + 结构写实**：解剖比例、体积明暗、毛发质感三项对齐真实动物；**不承诺照片级**，也不承诺与某个真实品种一一对应。仓库内无外部美术资源、不下载网络素材，全部由脚本程序化生成。

### 2.2 形象规格（替换 v1.1 §1.2 的画风行，其余沿用）
| 维度 | v1.1（扁平贴纸） | v1.2（结构写实） |
|------|------------------|------------------|
| 轮廓 | 统一深色粗描边（6px） | 取消黑色描边，改用同色系边缘压深 + 受光边反光 |
| 上色 | 平涂无渐变 | 径向渐变立体积 + 线性渐变压暗部，主光源固定左上并全身共用 |
| 质感 | 无 | 沿真实剪影的法线毛流 + 剪影内明暗纹理 + 猫科虎斑 / 犬科护毛 / 猴科脸环 |
| 比例 | Q 版大头（头身 ≈ 1:1） | 头身约 1:1.5，颅顶、口吻、颊部、臀腿分段建模 |
| 眼睛 | 圆点 + 高光 | 真实眼裂（内眼角低、外眼角按物种上扬或下垂）+ 虹膜渐变 + limbal ring + 猫科竖瞳 + 眼睑投影 |
| 尾巴 | 等宽圆头笔刷 | 由根到尖收细的锥形，尾尖带毛 |
| 落地 | 无 | 接触阴影，宠物"坐在地面上"而不是贴纸 |

### 2.3 验收标准
- Given 三套皮肤，When 生成素材，Then 每套 8 动作 × 4 帧共 32 帧、合计 96 帧全部落盘且可解码
- Given 同一动作的 4 帧，When 连续播放，Then 除呼吸/眨眼/摆尾相位外**逐像素可复现**（笔触随机数以皮肤+动作+帧号为种子）
- Given 三套皮肤并排目检，When 比较头骨、耳形、口吻、瞳孔、尾巴，Then 能一眼分辨物种，不得只靠颜色区分
- Given 素材帧，When 在 128×128 画布与 150% 缩放下渲染，Then 边缘不得糊成一团、明暗层次不得丢失

### 2.4 边界
- 单帧仍为 256×256 透明 PNG，体积增长不得让冷启动加载出现可感延迟
- 写实化只发生在离线生成脚本，运行期管线与依赖零变化

## 3. C3：离线小脑升级为统计 NLP（修订 v1.1 §2.3、§2.4）

### 3.1 用户故事
作为**没有 API Key、电脑也没有独显**的用户，我希望它听得懂我换着说法的同一句话，能回答常识问题，记得我上一句说过什么，并且会反问我——像在跟一个小程序聊天，而不是在背关键词表。

### 3.2 硬约束（用户明确提出，优先级高于效果）
| 约束 | 落实方式 |
|------|----------|
| 低配机器可跑（无 GPU / 仅集显） | 不引入任何生成式模型（含 0.5B 级小模型）；全部为统计方法，单次回复纯本地毫秒级 |
| 不影响日常办公 | 分词词典**惰性加载**且只在聊天工作线程触发，绝不进冷启动与 UI 线程；内存增量实测约 +70MB，未安装时自动退回内置零依赖分词 |
| 隐私 | 会话内记忆**不写盘、不上传**，清空会话或退出即忘；本地模式全程不联网 |

### 3.3 能力清单
| 能力 | 说明 | 覆盖下限 |
|------|------|----------|
| 意图泛化 | 关键词未命中时，由统计分类器判断意图，支持"我心态有点崩""周一要交的东西还没动"这类没写进词表的说法 | 20 类意图（v1.1 的 16 类 + 压力/工作/讲故事/求建议） |
| 知识问答 | 语料库检索作答，问法与答案分离；用户原话出现在语料里时按整句精配优先 | 20 条知识条目（健康、猫狗习性、专注方法、情绪、冷知识、隐私说明等） |
| 话题跟踪 | 记录本轮/上一轮话题实词，供追问与建议引用 | 会话内 |
| 会话内记忆 | 记住用户告诉它的名字与"正在做的事"，后续回复自然称呼与引用 | 姓名 + 当前活动 |
| 主动反问 | 用户只回"嗯""然后呢"时，接住上一轮话题把球踢回去，不冷场 | 4 类反问模板 |
| 分词后端 | 优先使用第三方中文分词，缺失或异常时退回内置 bigram，功能不中断 | 2 个后端 |

### 3.4 验收标准
| 编号 | Given / When / Then |
|------|---------------------|
| AC-BRAIN-1 | Given 未配置 api_key，When 用户说"我心态有点崩"（词表未收录该说法），Then 被识别为压力类并给出安抚回复，不落入兜底 |
| AC-BRAIN-2 | Given 未配置 api_key，When 用户问"番茄工作法是什么"，Then 命中知识条目并给出该条答案，而不是通用引导语 |
| AC-BRAIN-3 | Given 上一轮用户说过"我在写代码"，When 用户只回"然后呢"，Then 回复中引用"代码"这一话题继续追问 |
| AC-BRAIN-4 | Given 用户说过"我叫林克"，When 之后打招呼或求建议，Then 回复带上"林克"；When 清空会话，Then 不再出现该名字 |
| AC-BRAIN-5 | Given 用户输入与语料完全无关（乱码、纯虚词），When 回复，Then 走兜底且**不得**给出语料里某条看似相关实则答错的答案 |
| AC-BRAIN-6 | Given 未安装第三方分词库的环境，When 完成上述 1~5 全部场景，Then 行为一致（分词后端自动降级），测试全绿 |
| AC-BRAIN-7 | Given 应用冷启动，When 尚未发过任何一条消息，Then 分词词典**未被加载**（不出现词典加载日志） |
| AC-BRAIN-8 | Given 本地小脑运行中，When 检查磁盘与网络，Then 无新增文件写入、无网络请求 |

### 3.5 对 v1.1 的替换
- v1.1 AC-LOCAL-3「未命中任何话题走反射式兜底」**仍然成立**，但兜底不再是"关键词表最后一格"：必须先经过意图分类、话题追问、知识检索三层，全不命中才兜底
- v1.1 §2.4「话题覆盖下限 16 类」上调为 **20 类**，并新增"知识问答"这一独立能力维度
- v1.1 §2.4「中文关键词直接子串匹配」保留为**第一优先级**（规则命中零歧义、最快），统计层只在规则未命中时介入

## 4. 范围外（本版新增项）
- 生成式对话模型（本地或云端小语言模型）与其推理调度、显存/内存治理
- 照片级或真实品种素材、外部美术采购、AI 生图素材的版权与分发
- 跨会话的长期记忆持久化（本版记忆只在会话内）
- 皮肤素材的在线下载与热更新
- 语音输入、OCR、屏幕理解等非文本感知通道
