# 桌面宠物 WisePet PRD v1.34

- 版本：v1.34
- 状态：已实现（待评审）
- 日期：2026-11
- 性质：增量需求（度量口径校准 + 模型能力护栏 + 主动关怀闭环），补登 markdown 渲染改动；不回改历史版本

## 0. 背景与动机

本版承接两条线：

1. **补登上一轮遗留**：`AGENT.md` §3 记录的「气泡/历史窗完整 markdown + 拖拽缩放」已实现但标注「文档待补 FR/NFR v1.34」，本版正式补登为 R1。
2. **战略收口三件事**：项目已铺开 15+ 功能模块（陪伴 / AI 聊天 / 记忆 / RAG / Agent / 番茄钟 / 周报 / 成长 …），下一步不是继续加功能，而是收口——让北极星可测可信、让最大差异化（AI 对话）不被弱模型拖垮、让宠物从「你叫它才动」变成「会主动找你」。据此新增 R2~R4。

所有这些都守住既有底线：零新增运行时三方依赖（mistune 为上轮 UI 可选依赖，缺则降级）、全本机不上报、不改状态机白名单与事件契约、新推送全走打扰预算。

## 1. R1 完整 markdown 渲染与拖拽缩放（补登）

- 气泡与历史窗的助手回复走完整 markdown 渲染：标题 / 加粗 / 斜体 / 删除线 / 行内代码 / 代码块 / 引用 / 有序无序列表 / 表格 / 链接 / 分隔线，统一贴纸风内联样式；
- AI 输出的原始 HTML 一律转义（`escape=True`），注入无门；远程图片降级为可点链接，守隐私口径；
- 气泡与历史窗右下角可拖拽缩放：记住用户拖过的宽度，流式自动布局不再覆盖；高度随内容自适应；链接可点开外部浏览器；
- 用户消息保持纯文本原样显示（不渲染 markdown），语义更可预期。

## 2. R2 度量口径校准（让北极星可测可信）

背景：`docs/产品规划.md` §4 早已定义北极星为「有效互动天数」（提醒被确认 / 发过消息 / 用过任一工具），但旧 `compute_metrics` 的 `active_days = len(days)` 把一次崩溃、一次被动弹窗也算成活跃，把北极星算虚高；文档写了「空闲 CPU / 通知关闭率」护栏却没有采集项。

- 新增**有效互动天数 `engaged_days`**：只统计当天出现过 `msg:sent` / `tool:used` / `reminder:confirmed` 任一事件的天数；与「活跃天数」刻意分开，后者口径不变、保持兼容；
- 补齐有效互动埋点：发消息 `msg:sent`、工具调用 `tool:used`（按实际调用次数）、提醒确认 `reminder:confirmed`；
- 新增**模型质量护栏 `ai_fallback_rate`**：模型失败数 / 模型请求数，口径只算真正失败（`model:fail`），「lite 档不走工具」是正常路由不计入；配套埋点 `model:request`（每次 AI 请求）与 `model:fail`（每次错误事件）；
- 新增**四个护栏红黄绿灯**（`guardrail_status` 纯函数）：打扰平衡（提醒关闭率 > 50% 亮 warn）、大脑可用（失败率 > 50% 亮 warn）、运行稳定（崩溃 ≥ 3 亮 warn）、七日留存（满 7 天但未留存亮 warn，未到 7 天显示 n/a）；
- 消费端：命令面板「陪伴指标」显示北极星 + 四个护栏灯；「陪伴统计」面板顶部显示 `有效互动 N 天 · 北极星` 与四个灯（●绿 / ▲橙 / ○灰）。「清空本地埋点」行为不变。

## 3. R3 模型能力护栏（不让弱模型拖垮核心体验）

背景：`AGENT.md` 已登记弱模型（如 glm-4-flash）不守 function calling 协议、会编造本地生活店名（v1.33 才补了 `nearby_pois` 的防编造约束）。AI 对话是本产品区别于普通桌宠的最大差异化，体验硬伤出在核心上。

- 新增**模型能力分级**（`domain/model_capability.py`）：按模型名启发式推断 lite / standard / pro 三档（flash / lite / mini / haiku / turbo / nano → lite；opus / gpt-4.1 / gpt-4o / claude-3.7 / r1 / o3 等 → pro；其余 standard）；
- **工具循环准入**：lite 档自动禁用 agent 工具循环（`tools_allowed`），从机制上堵住弱模型编造事实；普通聊天不受影响，不把低成本用户挡在门外；总开关关闭时一律不放行；
- **能力边界提示**：lite 档在系统提示词追加「查不到别编造」约束（实时/本地事实没有工具结果就诚实说不知道）；非 lite 档不注入，不浪费 prompt；
- 可观测：lite 档拦截记 `feat:tier_lite_blocked` 功能事件（属功能渗透，不算失败）。

## 4. R4 主动关怀闭环（从「按点找你」到「看情况找你」）

背景：`event_triggers.py` 已有回来 / 深夜 / 连着专注三条规则，`QuietBudget` 已有每日总量与单来源上限。本版在不破坏断网可用与零联网底线的前提下扩展关怀。

- 新增**节气关怀**：本地公历近似节气表（误差约 ±1 天，不接联网 API），只在有情绪价值/生活提示的 10 个节气（立春 / 春分 / 立夏 / 夏至 / 立秋 / 秋分 / 立冬 / 冬至 / 大寒 / 大暑）触发一句关怀；
- 新增**情境评分 `context_score`**：专注 / 勿扰直接 0 分（不打招呼），深夜（23 点后、7 点前）与高忽略率（> 50%）降权，分数为 0 时不发；
- 节气关怀作为一条**候选**与既有情境规则共用同一天的去重集合与每日总量上限，发话前先过情境评分，发出后照旧统一走 `QuietBudget` 闸门（不开打扰后门）；
- 新增**打扰反馈降频 `suggested_interval`**（纯函数，供后续提醒间隔接线）：忽略率过半时把周期提醒间隔翻倍。本版提供并测试该能力，组装接线留给后续版本。

## 5. 验收项

| 组 | 验收 |
|---|---|
| AC-MD-1 | AI 回复 markdown 真渲染（加粗/列表），原文仍是 `current_text` 纯文本口径；原始 HTML 被转义、星号不原样露出 |
| AC-MD-2 | 气泡/历史窗右下手柄可拖宽，拖过后流式自动布局不覆盖用户宽度；链接可点开外部浏览器 |
| AC-METRIC-1 | `engaged_days` 只数有效互动事件，崩溃/弹窗/启动不算；与 `active_days` 口径分离且后者兼容 |
| AC-METRIC-2 | 四个护栏红黄绿灯按阈值正确切换；未到第七日显示 n/a；命令面板与统计面板均可见 |
| AC-MODEL-1 | lite 档按模型名正确识别；lite 禁用工具循环且注入防编造提示；pro/standard 正常走工具 |
| AC-MODEL-2 | 配置覆盖值非法/空值回落推断档；模型失败率只算 `model:fail`，不计正常路由 |
| AC-CARE-1 | 节气关怀仅指定节气日触发、当日去重、计入每日上限；专注/勿扰/深夜不发 |
| AC-CARE-2 | 情境评分与打扰反馈降频为纯函数、边界正确；所有关怀仍走 `QuietBudget` |

## 6. 范围外

- 不新增天气/日历联网 API（与断网可用底线冲突，节气用本地近似日期）；
- 不改 `compute_metrics` 既有字段语义（`active_days` 等保持兼容，新增字段另起）；
- 不把 `suggested_interval` 接到提醒服务（本版只提供并测试纯函数，避免改提醒节奏引入回归）；
- 不做模型档位的设置窗 UI（本版纯按模型名推断，用户可换模型名切换档位，显式下拉留后续）；
- 不做北极星的跨版本趋势图 / 导出（看板只展示当前快照）。
