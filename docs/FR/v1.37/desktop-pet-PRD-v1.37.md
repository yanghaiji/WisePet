# 桌面宠物 WisePet PRD v1.37

- 版本：v1.37
- 状态：已实现（待评审）
- 日期：2026-11
- 性质：增量需求（近期处境驱动的「真正自然的主动」），不回改历史版本

## 0. 背景与动机

v1.36 落地的主动仍是「定时任务式」——到点报天气、沉默几天问候、节气问候。它们能
覆盖「按点找你」，但覆盖不了「看情况找你」：用户说「最近天天加班」，宠物当次回应
后就忘了，接下来几天照常推娱乐内容、聊得兴高采烈，与用户的真实处境脱节。

本版补上「理解语境后的主动」：让用户**明说的客观近况**（加班 / 备考 / 生病 / 搬家 /
出差 / 面试）在接下来几天持续影响回复语气与主动关怀——这是「它懂你」的关键一步。

底线：只看用户**明说的客观事件**，不推测内心情绪（守 AGENT「不猜情绪」）；全本机、
不联网、不上传；主动关怀仍走 QuietBudget。

## 1. R1 近期处境识别（带时效，只认明说的）

- 处境类别：加班 / 备考 / 生病 / 搬家 / 出差 / 面试，各有默认持续天数（7~14 天）；
- 只从**用户第一人称明确陈述**识别（「最近天天加班」「我感冒了在吃药」）；
- 问句 / 转述他人（「我朋友加班」）/ 玩笑段子一律不记——宁可漏，不可乱；
- 同类处境再次说出时刷新时效（覆盖更新），不叠加多条；
- 过期自然消退，从存储中清理。

## 2. R2 回复贴合处境（提示词层）

- 处境有效期内注入系统提示词：告诉模型「用户最近在加班/备考…」，要求回复自然体贴、
  少推娱乐玩闹话题、不反复追问、不替用户表达情绪；
- 与 v1.36 的人格锚、情绪语气、可发现性并列，同在提示词尾部（弱模型对尾部敏感）；
- 处境过期后提示词不再注入，无需用户手动关闭。

## 3. R3 处境驱动的主动关怀

- 处境新鲜时偶尔一句贴合的话（「看你最近老加班，别熬太狠，记得喝口水」）；几天后
  话术自然变化（「还在加班呀？注意身体，我陪你收个尾」）；
- **每天最多一次**，按自然日去重；与沉默关怀（v1.35）、惦记（v1.28）、节气/天气
  共用 QuietBudget 总闸门，不新增推送通道；
- 识别不到处境时完全不动——不猜测、不打扰。

## 4. R4 配置与范围

- `CompanionSettings.situation_enabled`（默认开）：关闭后不识别、不注入、不主动关怀；
- 设置项随 `companion` 分节持久化（`to_dict` / `from_dict` 自动往返）。

## 5. 验收项

| 组 | 验收 |
|---|---|
| AC-SIT-1 | 只识别第一人称明确近况：加班/备考/生病等命中；问句、转述、玩笑不记 |
| AC-SIT-2 | 处境带时效：同类刷新、过期自动清理；有效期内提示词注入贴合、过期即停 |
| AC-SIT-3 | 主动关怀每天最多一次、话术随新鲜度变化、走 QuietBudget、可配置关闭 |
| AC-SIT-4 | 全程本机：无联网、无上传、无情绪推测 |

## 6. 范围外

- 不做 AI 语义理解处境（用关键词保守识别，零联网零成本；换说法可能漏，宁可漏不可乱）；
- 不推测用户情绪/心理状态（只看客观事件）；
- 不做处境保险/日程联动（不接日历 API）；
- 不长留：处境过期即清，不做历史档案。
