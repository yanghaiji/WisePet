## 1. 问题定位（真机实测，不是猜测）

改造前同一批输入的实测结果，四条病灶各自可复现：

| 病灶 | 实测证据 | 性质 |
| --- | --- | --- |
| **抢话题** | 用户「我心态有点崩」→ 回复「**我**心情低的时候会原地转三圈再趴下」 | 文案取向：所有话术以宠物视角起句 |
| **无差别状态播报** | 打招呼、问功能、倾诉，都会挂上「开心得尾巴都在打转 / 肚子饱饱的 / 精力满满」 | 状态感知（v1.1）被塞进与状态无关的句子 |
| **求知问句被状态词截胡** | 「猫咪为什么喜欢睡觉」→ 命中睡眠规则，答成宠物自己的精力 | 路由优先级：关键词层无条件先于知识层 |
| **兜底复读乱码** | 「asdfgh」→「喵？「asdfgh」我接不住」 | 把用户原文当"我在听"的证据，效果相反 |
| **上限太窄** | 20 类意图 / 20 条知识 / 每类 4~6 句样本 | 语料规模，随便聊两句就落到覆盖外 |

## 2. 需求条目

- **R1 先接住用户**。倾诉、说自己在做什么、求建议这三类输入，回复的**第一句**必须指向用户说的内容或情绪
  （引用他句中的实词、承认他的状态），宠物自己的情况最多作为收尾点缀。
- **R2 状态播报有触发条件**。心情/饱食/精力只在用户**主动问宠物**（"你心情怎么样""你饿不饿""你困吗"）时出现。
  其余句子出现即视为缺陷。
- **R3 求知问句优先**。句子带疑问标记（为什么/是什么/怎么/…）且知识层能高置信接住时，
  必须由知识层回答，不得由"报宠物自己状态"的规则接走。求对策（"我心态崩了怎么办"）仍属用户内容型，不被知识层抢走。
- **R4 兜底给路标，不复读**。听不懂时：① 不原样念用户的话（尤其无实词的乱码）；② 报 3 句**语料里真能答**的问法；
  ③ 例子随轮次轮换，不得每次同样三句。
- **R5 语料规模下限**。20 类意图、**40 条知识**、每类意图**不少于 8 句**样本、每条知识不少于 3 个问法变体与 2 个可互换答案。
  一条知识只围着一个问题转——答案池必须能回答它自己的任何一个问法。
- **R6 首句不自曝能力档位**。"现在是本地小脑模式"这类说明不得挂在第一句回复后面；
  它出现在用户问「你能做什么」时。

## 3. 验收标准（本地链路，全程离线）

> **编号说明**：本版沿用 `AC-BRAIN-n` 前缀但**重新编号**。v1.2 的 AC-BRAIN-1~6 描述的是改造前取向，
> 其中「先接住用户」尚未成立者由本章对应条目**替换**；v1.2 的 **AC-BRAIN-7（冷启动不加载分词词典）** 与
> **AC-BRAIN-8（无磁盘写入、无网络请求）** 与取向无关，**继续有效**。引用时请带版本号以免歧义。

- **AC-BRAIN-1**：依次输入「我心态有点崩」「我心情不好」「今天被组长说了一顿」，回复中不出现任何心情/饱食/精力播报文案。
- **AC-BRAIN-2**：「猫为什么喜欢睡觉」「睡不着怎么办」「狗为什么摇尾巴」三条均走知识层，答案与该问题对应（不得答成纸盒、不得答成"我精力满满"）。
- **AC-BRAIN-3**：「你现在感觉怎么样」「你饿不饿」仍给出三档状态播报（R2 的反面对照，防止改过头）。
- **AC-BRAIN-4**：先说「你好」再输 `asdfgh`，回复不含「你好」也不含 `asdfgh`，且含「试试问」引导。
- **AC-BRAIN-5**：连续兜底 14 次以上，语料中的引导问法应全部出现过（例子池轮换含尾部回绕）。
- **AC-BRAIN-6**：首条回复不含"本地小脑模式"说明；问「你能做什么」时含该说明。

## 4. 边界与不承诺

- 本地小脑是**统计方法 + 有限语料**，上限是"不智障"，不是"聪明"。需要真正的对话质量请接 AI 链路（v1.0 起即支持）。
- 语料只覆盖健康习惯、猫科/犬科/猴科习性、陪伴与工作方法；**不含需要联网核实的事实**（天气、新闻、汇率）。
- 记忆仍只在本次会话内，不写盘、不上传；`reset` 即清空。
- 时间类回答只给"时段 + 整点"的模糊表述，不承诺精确到分。

## 5. 范围外（本版明确不做）

- 生成式模型、本地小参数量化模型、向量库检索增强（与"低配机器 + 不影响办公"的硬约束冲突）。
- 跨会话长期记忆（隐私边界优先）。
- 多轮任务的槽位填充与指代消解（"把上面那三点列成表格"这类结构性请求仍走 AI 链路）。
