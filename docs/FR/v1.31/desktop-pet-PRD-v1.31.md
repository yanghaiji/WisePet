# 桌面宠物 WisePet PRD v1.31

- 版本：v1.31
- 状态：已实现（待评审）
- 日期：2026-11
- 性质：增量需求（记忆体系升级 + 本地多用户），不回改历史版本

## 0. 背景

v1.30 落地 function calling 后的既定路线：会话摘要记忆 → 实体记忆泛化 →
embedding 语义检索。叠加登录注册讨论的产物：本地 profile（机内多用户）。
共同底线不变：零新增三方依赖、全本机、不上传、可遗忘。

## 1. R1 会话摘要记忆（ConversationSummaryMemory 自研）

- 被 `max_turns` 截断的旧对话不再消失：每轮 observe 进缓冲，攒满 8 条由
  **后台线程**调一次 AI 把「旧摘要 + 新对话」合并压缩（≤600 字），绝不阻塞回复
- 摘要作为第二条 system 注入 messages；`summary.json` 跨重启有效
- 重启回灌时把「当天更早、已被截断」的轮次补进缓冲（reconcile）
- AI 生成失败静默等下次（摘要只增强、不添堵）；未配 AI / 开关关闭即整体停用

## 2. R2 实体记忆泛化

- 长期记忆从三键（名字/近况/项目）扩展为**任意自由事实**（key ≤24 字 / value ≤120 字，上限 50 条）
- 三种入口：正则三键（无 Key 也能记）+ agent `remember` 工具（function calling 时代模型主动记）+ 未来手动入口
- **时间衰减**：超 90 天的自由事实不再进提示词（时间线里仍可查看）；
  进提示词最多 8 条，新的优先
- 时间线对话框新增「记住的事」条目，勾选即真删（删事实 + 同步内存态）

## 3. R3 embedding 语义检索（混合检索）

- AI 服务新增「Embedding 模型」配置（per-profile 保存，切模型跟随）；
  助理区新增「语义检索」开关（默认关）
- `openai_client.embeddings()`：OpenAI 兼容批量调用，index 排序复原、错误分类一致
- `KnowledgeBase`：建索引时批量向量化（≤500 chunk，每批 32）；检索时
  **BM25 归一化 + 1.2×余弦** 混合打分；查询向量实时生成
- 任何失败（未配模型 / 网络失败 / 数量不匹配）都**降级纯 BM25**——语义只是增强
- 向量缓存 `knowledge.json` 本机；开关变化自动重建索引

## 4. R4 本地身份（profile）

- 同一台电脑多个人各用各的宠物，**零登录零服务器**：
  - 默认身份 = `~/.WisePet` 根目录（老用户零迁移）；新身份 = `~/.WisePet/profiles/<名字>/`
  - 名字只允许中英文/数字/下划线连字符（≤24 字），防路径穿越
  - `--profile=名字` 启动参数；命令面板「切换身份」记住下次启动用哪个（重启生效）
  - 单实例守卫端口按身份名派生：同身份互斥、不同身份可并行
- 每个身份独立的数据目录：配置 / SQLite 聊天 / 记忆 / 成长 / 日志全套隔离
- **不是账号体系**：无服务器、无凭证存储、无登录墙，呼应「本地可信」核心轴

## 5. 验收项

| 组 | 验收 |
|---|---|
| AC-SUM-1 | 缓冲攒满触发后台摘要、prefix 注入 messages、落盘跨重启 |
| AC-SUM-2 | AI 失败静默、禁用即停用、reconcile 只补被截断轮次（system 不进缓冲） |
| AC-MEM-1 | remember 同 key 覆盖、上限 50、空白拒绝、禁用即停 |
| AC-MEM-2 | 时间衰减排序 + TTL；时间线「记住的事」真删并同步内存态 |
| AC-RAG-1 | 建索引向量化、混合打分（无关键词重叠也能靠语义命中） |
| AC-RAG-2 | 三级降级：未配模型 / 构建失败 / 查询失败 → 纯 BM25，不炸 |
| AC-PROF-1 | 名字校验、目录隔离、active 持久化、守卫端口派生 |
| AC-CFG-1 | 新配置字段 roundtrip、设置窗 collect 不丢、embeddings 错误分类 |

## 6. 范围外

- 不做云账号 / 登录墙 / 多人在线聊天（与「本地可信」核心轴冲突，见产品规划 §11 决策）；
- 不做端到端加密同步（P3，等 D7 读数）；不用向量库（纯标准库余弦）。
