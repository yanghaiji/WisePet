# WisePet 意图协议（v2.1）

> 工具执行层的扩展点：大模型按本协议输出 JSON，本地程序负责执行。
> 未来插件系统注册新 `action` 时沿用同一通道。

## 工作方式

1. 系统提示词向模型声明本协议（见 `app/action_protocol.py: ACTION_PROMPT_GUIDE`）
2. 模型判断用户是否需要执行操作；需要时**只输出一个 ```json 代码块**
3. `app/action_protocol.parse_action()` 提取并严格校验；解析失败按普通聊天文本展示
4. 涉及写盘的操作（create_file / make_ppt）必须经用户弹窗确认才执行

## 动作清单

### remind 定时提醒
```json
{"action": "remind", "delay_min": 5, "text": "开会"}
{"action": "remind", "at_hm": "14:30", "text": "交日报"}
```
- `delay_min`：N 分钟后（≤ 43200）；`at_hm`：当天时刻，已过则排明天
- 限制：必须有 text；时间超出上限直接拒绝

### create_file 创建文件
```json
{"action": "create_file", "path": "D:/notes/a.md", "content": "文件完整内容"}
```
- path 必填；content 允许为空（创建空文件）；**弹窗确认后写入**

### make_ppt 生成演示文稿
```json
{"action": "make_ppt", "path": "D:/demo.pptx", "title": "标题",
 "slides": [{"title": "页标题", "bullets": ["要点1", "要点2"]}]}
```
- slides ≤ 30 页（清洗后非空页）；每页要点不限制数量但建议 ≤ 6；**弹窗确认后生成**

## 本地快速通道（不经过模型）

以下说法在发送给 AI 之前就被本地正则拦截执行，更快也不费 token：

| 说法示例 | 行为 |
|---|---|
| `5分钟后提醒我开会` / `30s后提醒我` | 一次性提醒（支持中英文单位、中文数字、半小时） |
| `每天14:30提醒我交日报` | 每日重复提醒（重启后自动恢复） |
| `取消所有提醒` | 清空全部挂起与每日提醒 |
| `专注25分钟` / `来个番茄钟` | 番茄钟计时，到点提醒休息并计入统计 |

## 新增动作的步骤

1. `app/action_protocol.py`：定义 Action dataclass + `_to_action` 分支 + `describe_action` 文案
2. `main.py::_handle_action`：执行分支（写盘类必须走 `_confirm_action`）
3. 系统提示词 `ACTION_PROMPT_GUIDE` 增加格式说明
4. 测试：`tests/unit/test_action_protocol.py`
