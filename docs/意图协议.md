# WisePet 意图协议

> 工具执行层的扩展点：大模型按协议发起操作，本地程序负责执行。
> v1.30 起支持**双模式**：原生 function calling（tools 协议，优先）与
> JSON-in-prompt（兜底）；未来插件系统注册新 `action` 时沿用同一通道。

## 两种模式

| 模式 | 触发 | 解析 | 说明 |
|---|---|---|---|
| **原生 tools**（优先） | 网关支持 OpenAI tools 协议且「工具调用」开关开 | 模型返回结构化 `tool_calls`，本地执行后以 `role=tool` 回喂，可多步循环 | 解析可靠性最高；多步任务（先读资料再回答）只有这条能做 |
| **JSON-in-prompt**（兜底） | 网关不支持 tools（按 base_url\|model 记忆降级）/ 开关关闭 | 模型在回复里输出 ```json 块，`parse_action()` 提取校验 | 老路径一条不丢；一轮只执行一个动作 |

降级按 `base_url|model` 记忆，同一网关本次进程内不重复试错；auth/网络等错误照旧上抛走既有错误链。

## 工具清单（原生 tools 模式，9 个）

只读 6 个（循环内直接执行，结果回喂）：
`read_file`（限资料文件夹内）、`list_folder`、`search_knowledge`（资料索引）、
`search_history`（历史聊天）、`recall_memories`（长期记忆）、`get_status`（宠物状态/托付）

写盘 / 排期 3 个（**不在线程内执行**，作为 pending_action 交回主线程走三级权限 + 预览确认 + 审计 + 撤销）：
`remind`、`create_file`、`make_ppt`

## 安全边界

- 只读工具限定「资料文件夹」信任域：防目录穿越、拒符号链接、单文件 ≤512KB；
- 写盘 / 排期动作永远经主线程的 `permission_required()` 三级权限与 `ActionConfirmDialog`
  完整预览确认，agent 线程内绝不直接写盘；
- agent 循环上限 6 步，超限强制总结；工具结果回喂截 6000 字符，防止撑爆上下文。

## 工作方式（JSON-in-prompt 兜底模式）

1. 系统提示词向模型声明本协议（见 `app/action_protocol.py: ACTION_PROMPT_GUIDE`）
2. 模型判断用户是否需要执行操作；需要时**只输出一个 ```json 代码块**
3. `app/action_protocol.parse_action()` 提取并严格校验（`_extract_json_object` 支持围栏块与裸对象，含字符串内花括号）；解析失败按普通聊天文本展示
4. `permission_required()` 判权限：定时提醒不写盘恒为 `auto`；写盘类按「写盘权限」设置
5. 需要确认时由 `ui/action_confirm.py::ActionConfirmDialog` 展示 **完整路径 + 将写入的正文/大纲**，用户点「执行」才落盘；可勾选「以后都允许」
6. 执行结果写入 `~/.WisePet/actions.json` 审计日志；写文件类保留快照用于「撤销上一次写文件」

## 动作清单

### remind 定时提醒
```json
{"action": "remind", "delay_min": 5, "text": "开会"}
{"action": "remind", "at_hm": "14:30", "text": "交日报"}
```
- `delay_min`：N 分钟后（≤ 43200）；`at_hm`：当天时刻，已过则排明天
- 限制：必须有 text；时间超出上限直接拒绝

### create_file 创建文件
```json
{"action": "create_file", "path": "D:/notes/a.md", "content": "文件完整内容"}
```
- path 必填；content 允许为空（创建空文件）；**弹窗确认后写入**

### make_ppt 生成演示文稿
```json
{"action": "make_ppt", "path": "D:/demo.pptx", "title": "标题",
 "slides": [{"title": "页标题", "bullets": ["要点1", "要点2"]}]}
```
- slides ≤ 30 页（清洗后非空页）；每页要点不限制数量但建议 ≤ 6；**弹窗确认后生成**

## 本地快速通道（不经过模型）

以下说法在发送给 AI 之前就被本地正则拦截执行，更快也不费 token：

| 说法示例 | 行为 |
|---|---|
| `5分钟后提醒我开会` / `30s后提醒我` | 一次性提醒（支持中英文单位、中文数字、半小时） |
| `每天14:30提醒我交日报` | 每日重复提醒（重启后自动恢复） |
| `取消所有提醒` | 清空全部挂起与每日提醒 |
| `专注25分钟` / `来个番茄钟` | 番茄钟计时，到点提醒休息并计入统计 |

## 权限、确认与审计（v1.21 / v1.25）

| 环节 | 实现 | 用户入口 |
|---|---|---|
| 三级权限 | `permission_required(action, setting)`：`auto` 直接执行 / `confirm` 每次确认 / `deny` 一律拒绝；非法配置保守回落 `confirm` | 设置 →「体验与隐私」→ 写盘权限 |
| 记住授权 | 确认弹窗可勾「以后都允许」（需打开「记住授权」开关） | 设置 →「体验与隐私」→ 记住授权 |
| 完整预览 | `action_preview(action)`：创建文件给出目标路径 + 全文；PPT 给出每页标题与要点 | 确认弹窗正文 |
| 审计日志 | `app/action_audit.py::ActionAudit` 落 `~/.WisePet/actions.json`，只记动作类型 / 路径 / 时间 | 右键 / 命令面板「最近执行的操作」 |
| 一次撤销 | 写文件前保留快照，右键「撤销上一次写文件」可回滚 | 右键菜单 |

**安全约束**：写盘类动作永远走确认或显式授权，模型无法绕过；`deny` 下直接拒绝并给出气泡说明。
定时提醒不写盘，恒为 `auto`（快速通道也不经模型）。

## 新增动作的步骤

1. `app/action_protocol.py`：定义 Action dataclass + `_to_action` 分支 + `describe_action` / `action_preview` 文案 + `permission_required` 分级
2. `main.py::_handle_action`：执行分支（写盘类必须走 `_confirm_action` 与审计）
3. 原生 tools 模式：`app/agent_tools.py` 加 `_fn` schema + `AgentToolbox.execute` 分支（只读直接返回文本，写盘返回 Action 对象）
4. 系统提示词 `ACTION_PROMPT_GUIDE` 增加格式说明
5. 测试：`tests/unit/test_action_protocol.py`、`tests/unit/test_agent_loop.py`、`tests/unit/test_roadmap_features.py`
