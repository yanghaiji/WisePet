# 规约

## 项目规范
1. 所有需要临时下载的都需要放到本项目目录下，用完及时清理
2. 所有的需求设计，都放在FR下，需要进行版本管理，有一个总项目的预览
3. 所有的技术设计，都放在NFR下，需要进行版本管理，有一个总项目的预览
4. 开发中所有的AGENT规约和实现思路/规约/验证方式等都需要记录在AGENT.md里
5. 如果项目需要进行升级，如果用户超过1分钟未进行确认，你默认选择你推荐的选择，如果多选，则全部选中

## 测试规范
1. 你测试运行的服务，在任务结束时，必须关闭相关服务

## 文档规范
1. 完成项目时，需要检测本项目是否有说明文档，说明没用，需要创建一个README.md，用于项目说明；如果有的话，请进行更新
2. 当你发现需要加入新的约束可以更好的维护项目时，可以将相关约束引入到本项目中
