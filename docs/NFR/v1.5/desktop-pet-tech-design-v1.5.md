## 2. 问句优先层（唯一的路由改动）

```python
name, handler = self._find_keyword(text)
if handler is not None:
    if name in SELF_STATE_RULES and self._engine.is_question(text):
        asked = self._engine.lookup_strong(text)      # 只收高置信
        if asked is not None:
            ... return "knowledge", ...
    answer = handler(text, ctx)                        # 否则仍走规则
```

三条判据缺一不可，各自挡掉一类翻车：

| 判据 | 挡掉的问题 |
| --- | --- |
| `name in SELF_STATE_RULES` | 「我心态崩了**怎么办**」是求对策不是求知，不能被百科式答案抢走（stress/work/advice 不在集合内） |
| `is_question(text)` | 「你去睡吧」「现在几点了」这类陈述/指令不应触发检索 |
| `lookup_strong()` 高置信 | 模棱两可的 BM25 分不得翻盘——弱命中留给原规则，比乱抢安全 |

**规则序调整**：`stress` 移到 `feel` 之前。「我心情不好」同时含「心情」（feel 词表）与「不好」，
feel 先接住就会答成宠物自己的心情——这是真机「抢话题」的第二条成因，与文案无关，纯顺序问题。

## 3. 展示层的两个过滤器（不是检索层）

`_matter()` 决定"回复里引用用户哪个词"，抽不到就说「这件事」：

| 过滤 | 集合 | 为什么在展示层而不是停用词 |
| --- | --- | --- |
| 泛词 | `VAGUE_MATTERS`（心情/情绪/状态/压力/心态/不好/…） | 「不好」是「心情不好怎么调节」这条知识的主要检索手段，拉黑进停用词会伤召回（实测如此，改回来过）；只在引用时当它不存在 |
| 人称开头 | `PERSON_PRONOUNS`（我你他她它咱您） | jieba 会把「我该」切成一个词，引用出来是「「我该」你能把选项说具体一点吗」 |

## 4. 兜底的新形态

`_fallback()` 两分支，都不复述用户原文：有实词 → 「我听到的是「x」，但这句我接不住」+ 3 句例子；
无实词 → 「喵……这句我没听懂」+ 3 句例子 + 一句引导。

`EXAMPLE_ASKS` 从 `KNOWLEDGE[:12]` 的 `asks[0]` **现场生成**而不是写死，配 `_turn % len(pool)` 轮换并支持尾部回绕：
语料删改后例子自动跟着变，不会出现「举出一个自己答不了的问题」。

## 5. 语料的三条硬约束（由 `test_corpus.py` 守着）

1. 每类意图 ≥8 句、知识 ≥40 条（实际 41）、每条知识 ≥3 问法 + ≥2 个互不重复的答案；
2. `INTENT_SAMPLES` 的键集合必须等于 `LocalResponder._rules` 的规则名集合（防分类器产出路由表外意图）；
3. **状态类意图的样本里不得出现「为什么」**——那会把"该查知识"训成"该报状态"；
   并新增一条结构不变量：`每条 ask 单独检索都必须回到自己`（曾把「眨眼/纸盒/猫睡觉」塞进同一条，问猫为什么爱睡觉答出了纸盒）。

## 6. 泛化门槛的取舍

语料扩容过程中，「我心态有点崩」的 NB 后验掉到了 **0.245**，卡在 `INTENT_MIN_CONF = 0.25` 下面
（其它 19 类的样本被加多后稀释了类内词元质量，而这一类新增的两句话与它无关）。

- **没有下调阈值**：0.25/0.18 是 v1.3 标定过的组合，为一句文案动全局门槛，代价是未知句子大面积误接管。
- 改为**把这句真实说法本身补进语料**（stress 类 +4 句），后验回到门槛之上，且能力边界如实扩大。
- 结论：小语料系统里"泛化不够"多数时候是**语料缺口**，不是算法缺陷；先补语料，再谈调参。

为它们写测试等于为不可能的输入编造断言。

## 8. 已知遗留

- NB 对**短句 + 无关键词**仍弱（0.245 这种临界值不止一处）；继续提升只能靠加语料，或接受下调门槛的精度代价。
- 兜底例子只取前 12 条知识的首个问法，后面 28 条永远不会被举例出来——够用，但不是"最全"。
- 寒暄池轮换按 `_turn` 取模，连续两句不同意图仍可能撞同一 index（不同池长度不同所致，不影响正确性）。
- 「你能做什么」之外的功能引导只在 `GUIDE_LINES` 出现一句"接上 AI 大脑"，新用户可能不知道本地模式与 AI 模式的差别。
