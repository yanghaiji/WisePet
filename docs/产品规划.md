# WisePet 产品规划（v2.x 路线图）

> 定位一句话：**住在桌面上的 AI 伙伴**——先是「活物」（有状态、有性格、有位置感），
> 再是「助理」（能替你做事），最后是「习惯」（每天不看它一眼会觉得少了点什么）。

---

## 0. 产品现状盘点（v1.x 已具备的资产）

| 资产 | 竞争壁垒 |
|---|---|
| 活物感：漫游/睡觉/心情/求助，全屏感知 | 多数桌宠只是循环播动画 |
| 本地小脑：无 Key 也能聊，隐私零上传 | 数据全在本机，是差异化卖点 |
| 工具执行层：一句话提醒 / 建文件 / PPT / 新闻 / 鼓励 | 已有「意图 JSON → 本地执行」的协议雏形 |
| 多模型方案：聊天窗一键换脑 | BYOK（用户自带 Key），零 API 成本转嫁 |
| 多卡通知：标题区分、统一驻留、确认交互 | 通知系统已产品化，可承载一切后续推送 |

**核心结论：地基（意图协议 + 通知系统 + 多模型）已经打好，v2.x 应该沿「助理」和「陪伴」两条线纵深，而不是继续堆零散功能。**

## 1. 用户画像与场景优先级

| 人群 | 核心场景 | 付费潜力 |
|---|---|---|
| 程序员/知识工作者（主力） | 番茄钟、久坐提醒、日程、截图问 AI | 高 |
| 独居/远程办公者 | 陪伴感、主动关怀、鼓励 | 中 |
| 桌面美化爱好者 | 皮肤、动作品质、桌搭氛围 | 高（为爱付费） |

## 2. 版本路线图

> 阅读提示：各版本下面罗列的是**原始规划条目**（保留以便追溯），实际完成状态以每段的
> `✅ 已落地 / ⏳ 待做` 汇总行与 §6、§7 结清记录为准；FR v1.19~v1.26 已把大量条目提前兑现。

### v2.0 「站稳」——打磨与信任（1~1.5 月）
*目标：把现有功能从「能用」做到「可靠」，建立自动更新通道，为后续迭代铺路。*
*✅ 已落地（2026-11）：陪伴统计面板、勿扰时段、配置损坏自动备份回滚（原有原子写 + 损坏改名）、接入系统通知中心（可选，跨平台托盘 showMessage）。*
*⏳ 待做：自动更新（需发布基础设施）、性能基线告警。*

- **自动更新**：检查新版本 + 下载安装（无更新通道，每次迭代都要用户手动换包，流失率最高的环节）
- **通知进系统通知中心（可选）**：自绘气泡保留「陪伴感」，但提供接入 Windows 通知中心的选项——**通知疲劳是这类产品第一大流失原因**，让用户自己选打扰方式
- **崩溃与错误自愈**：AI 调用失败重试队列、配置损坏自动备份回滚
- **性能基线**：空闲 CPU <1%、内存上限告警；开工管理者最在意这个
- **数据面板（隐藏彩蛋）**：右键查看「陪伴统计」——陪你多少天、提醒多少次、聊了多少句（情感线的种子）

### v2.1 「助理」——效率场景纵深（1~2 月）
*目标：从「会聊天」到「替你记住事、管好时间」。*
*✅ 已落地（2026-11）：番茄钟+专注统计（focus.json）、提醒持久化+每日重复+取消（reminders.json）、全局快捷键 Ctrl+Alt+P（Windows）、截图问小墨、意图协议文档化（docs/意图协议.md）。*

- **番茄钟 + 专注统计**：「陪我专注 25 分钟」→ 到点休息提醒 + 当日专注时长统计（与久坐数据打通）
- **日程提醒升级**：一句话提醒已支持绝对时间（14:30）；补上「每天/每周重复」与跨天持久化（重启不丢）
- **全局快捷键**：一键唤起聊天窗 / 截图问 AI，不用去找猫
- **截图问答产品化**：图片上传已支持多模态，包装成「圈选屏幕问小墨」——高频刚需
- **意图协议开放**：把 `{"action": ...}` 协议文档化，为插件生态铺路

### v2.2 「陪伴」——情感纵深（1~2 月）
*目标：让用户与宠物之间有「记忆」和「关系」。*
*✅ 已落地（2026-11）：成长体系（互动积分→等级/形态，growth.json + 统计面板）、回忆录（每周本地聊天周报，weekly.json）、语音说话 TTS（Windows System.Speech / macOS say，音量语速进设置）。*
*⏳ 待做：主动关怀（天气/节气本地 API）、心情细化（不同心情不同 idle 动画权重）。*

- **成长体系**：喂食/抚摸/陪伴天数积累 → 等级与形态变化（小猫→成猫），掉线太久会「想你」
- **回忆录**：每周日推送「本周我们聊了 N 句，你问我最多的是…」（本地数据，AI 生成周报）
- **主动关怀**：接入天气/节气（本地 API）——「今天降温了，出门加件衣服」
- **语音说话（TTS）**：提醒和回复可以开口说（Windows TTS 免费）；音量/开关进设置
- **心情再细化**：从三维数值走向可见的情绪表达（不同心情不同 idle 动画权重）

### v2.3 「生态」——开放与个性化（2 月+）
- **皮肤工坊**：素材包格式 + 社区分享；皮肤是这类产品最成熟的付费点
- **插件系统**：第三方注册新的 `action`（如「打开网站」「控制音乐」），工具层直接复用
- **语音输入（STT）**：对着小猫说话发消息
- **手机伴侣（远期）**：提醒同步到手机，人不在电脑前也不错过

## 3. 商业化设想（保持 BYOK 底线）

| 层 | 内容 | 定价思路 |
|---|---|---|
| 免费 | 全部核心：聊天、提醒、漫游、本地小脑 | 建立口碑与装机量 |
| 皮肤/形象付费 | 精品皮肤、专属动画、宠物种类 | 单买或月费，美学付费意愿最强 |
| 高级助理 | 云端模型代充（不想自己办 Key 的用户）、TTS 音色包 | 按量或订阅 |

**底线**：本地数据不上传、BYOK 永远保留——这是信任根基，动它等于自杀。

---

## 4. 北极星指标与护栏

- **北极星**：周活跃天中「有效互动天数」（提醒被确认 / 发过消息 / 用过任一工具）
- **护栏指标**：空闲 CPU、通知关闭率（用户关提醒 = 打扰失衡的强信号）、7 日留存
- **健康信号**：本地小脑使用占比（隐私卖点是否成立）、多模型方案配置率（高级功能渗透）

## 5. 风险与对策

| 风险 | 对策 |
|---|---|
| 通知疲劳 → 被卸载 | 统一驻留、勿扰时段、系统通知中心、打扰预算/降频、一键免打扰均已做；护栏转为盯「通知关闭率」埋点读数 |
| AI 成本转嫁给用户后的体验断层 | 未配 Key 的本地小脑必须持续可用且不难堪 |
| 桌宠品类同质化 | 活物感 + 工具执行层双壁垒，避免纯「卖萌播放器」 |
| 单人维护节奏 | 每个版本只做一个主题，测试覆盖不放松（当前 1350 passed / 94.37% 是资产） |

## 8. 核心三轴：轴①「持续性 / 从一直在到一直记得」结清（2026-11-11）

按「核心不是伙伴设定，而是共处关系」的三轴框架（持续性 × 主动性 × 本地可信），
先把轴①做透。四项全部基于**本机可观测事实**，零联网、零画像、零新增三方依赖；
对应 `FR v1.28` / `NFR v1.28`。

| 项 | 落地内容 | 用户入口 |
|---|---|---|
| 主动引用（惦记） | `domain/companion.py::pick_recall` 从本地聊天挑未兑现的惦记（排除命令句/太新/已完成），注入系统提示词；`CompanionService` 启动 3 分钟后、按自然日去重推一条「我还记得」 | 设置 →「主动惦记 / 惦记入脑」两个独立隐私开关；命令面板「我还记得什么」 |
| 情境化时间与状态 | `BehaviorContext` 加星期与「刚结束专注」；周一早晨小跑、刚结束专注伸懒腰、深夜去睡；话术注入「此刻情境」 | 设置 →「情境化」（关闭后旧行为逐字节一致） |
| 可干预的共处 | `PetController.interact()` 打断当下自主行为：摸一下→伸懒腰蹭回来、叫一声→抬头看你（SPEAKING） | 右键摸头；命令面板「叫一声小墨」 |
| 久别重逢 | `presence.json` 精确「上次出现」时间戳（避开被启动覆盖的 `last_updated` 与按天的 growth/telemetry），按 24/36/72h 分档本地问候，不等 AI 也必达 | 设置 →「久别问候 / 久别阈值」 |

**设计取舍**：惦记不做 AI 润色（确定事实本地秒出，AI 只负责在对话里接得自然）；

**验收**：新增 39 项回归（33 单测 + 6 UI），全量 `1389 passed / 0 failures`，改动文件 lints 0。
真机待目检：隔日开机问候、深夜/周一早晨动作差异、走动中摸头是否真打断、惦记气泡是否只出现一次。

**轴② A 类已结清**：见 §9。轴③及其它仍待做：自动更新与签名分发、winget 上架、
可复现构建 / SBOM、D7 真机读数、助理任务队列的写盘型托付与第三方 action 沙箱。

## 9. 轴②「主动性 / 从会说话到可托付」A 类结清（2026-11-11）

上一轮把「还能做的能力」分 A/B/C 三类，A 类为高价值、零外部依赖、可立刻做的五项，
现一次性全部落地，对应 `FR v1.29` / `NFR v1.29`。共同底线：零新增三方依赖、
全部本机事实、不上传、不画像、不猜测情绪，新推送一律计入打扰预算。

| 项 | 落地内容 | 用户入口 |
|---|---|---|
| 助理任务队列 | `TaskService` + `tasks.json`：`watch_file` / `followup` 两类、跨重启存活、30s→300s 退避重试、失败转 `failed` 并如实说明、只读沙箱（拒符号链接/限大小）、「搞定了」自动消解 | 直接聊天说「盯着 x.log，出现 ERROR 告诉我」；命令面板「我的托付」「取消全部托付」 |
| 本地文档 RAG | `KnowledgeBase`：显式指定文件夹 → 切块倒排 + BM25 近似检索 → 按当前问题注入提示词；默认关闭、白名单文本、总量上限、索引只落本机 | 设置 →「资料索引 / 资料文件夹 / 注入片段」；命令面板「重建资料索引」「资料索引状态」 |
| 事件驱动主动 | `EventTriggerService`：系统空闲 / 深夜 / 连着专注三条规则，按「规则×自然日」去重 + 每天封顶，非 Windows 空闲降级 | 设置 →「事件主动 / 情境上限」 |
| 可遗忘时间线 | `MemoryTimeline` 聚合 8 类本机数据 + `MemoryDialog` 勾选**真删**（按 key/按天/按条）+ 导出清单 | 命令面板「我记得你什么」 |
| 惦记清单化 | `pick_recalls` 多条并存 + 指纹去重 + 话题碎片定向消解（「周报搞定了」不影响「整理笔记」） | 设置 →「惦记条数」；命令面板「我还记得什么」 |

RAG 用 BM25 + bigram 而非向量库；事件源拒绝天气/日历云 API；
设置窗不加第 8 个分区（守既有 7 分区契约）。

**验收**：新增 45 项回归（35 单测 + 10 UI），全量 `1434 passed / 0 failures`，

## 11. 记忆体系升级 + 本地多用户（2026-11-11）

用户提出「登录注册 + 多人在线聊天」的设想，产品决策：**不做登录墙与云账号**——
与「本地可信」核心轴正面冲突（信任等级从「数据不出机器」降为「服务器承诺不上传」）、
登录墙是桌宠品类最贵的流失点、真人社交破坏「只属于我」的私密共处定位。
拆解出的真实诉求各有正确解法：机内多用户 → 本地 profile（本版落地）；
跨设备 → 端到端加密同步（P3）；用户间社交 → 否决。
