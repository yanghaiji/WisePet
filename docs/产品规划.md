# WisePet 产品规划（v2.x 路线图）

> 定位一句话：**住在桌面上的 AI 伙伴**——先是「活物」（有状态、有性格、有位置感），
> 再是「助理」（能替你做事），最后是「习惯」（每天不看它一眼会觉得少了点什么）。

---

## 0. 产品现状盘点（v1.x 已具备的资产）

| 资产 | 竞争壁垒 |
|---|---|
| 活物感：漫游/睡觉/心情/求助，全屏感知 | 多数桌宠只是循环播动画 |
| 本地小脑：无 Key 也能聊，隐私零上传 | 数据全在本机，是差异化卖点 |
| 工具执行层：一句话提醒 / 建文件 / PPT / 新闻 / 鼓励 | 已有「意图 JSON → 本地执行」的协议雏形 |
| 多模型方案：聊天窗一键换脑 | BYOK（用户自带 Key），零 API 成本转嫁 |
| 多卡通知：标题区分、统一驻留、确认交互 | 通知系统已产品化，可承载一切后续推送 |

**核心结论：地基（意图协议 + 通知系统 + 多模型）已经打好，v2.x 应该沿「助理」和「陪伴」两条线纵深，而不是继续堆零散功能。**

---

## 1. 用户画像与场景优先级

| 人群 | 核心场景 | 付费潜力 |
|---|---|---|
| 程序员/知识工作者（主力） | 番茄钟、久坐提醒、日程、截图问 AI | 高 |
| 独居/远程办公者 | 陪伴感、主动关怀、鼓励 | 中 |
| 桌面美化爱好者 | 皮肤、动作品质、桌搭氛围 | 高（为爱付费） |

## 2. 版本路线图

### v2.0 「站稳」——打磨与信任（1~1.5 月）
*目标：把现有功能从「能用」做到「可靠」，建立自动更新通道，为后续迭代铺路。*
*✅ 已落地（2026-11）：陪伴统计面板、勿扰时段、配置损坏自动备份回滚（原有原子写 + 损坏改名）、接入系统通知中心（可选，跨平台托盘 showMessage）。*
*⏳ 待做：自动更新（需发布基础设施）、性能基线告警。*

- **自动更新**：检查新版本 + 下载安装（无更新通道，每次迭代都要用户手动换包，流失率最高的环节）
- **通知进系统通知中心（可选）**：自绘气泡保留「陪伴感」，但提供接入 Windows 通知中心的选项——**通知疲劳是这类产品第一大流失原因**，让用户自己选打扰方式
- **崩溃与错误自愈**：AI 调用失败重试队列、配置损坏自动备份回滚
- **性能基线**：空闲 CPU <1%、内存上限告警；开工管理者最在意这个
- **数据面板（隐藏彩蛋）**：右键查看「陪伴统计」——陪你多少天、提醒多少次、聊了多少句（情感线的种子）

### v2.1 「助理」——效率场景纵深（1~2 月）
*目标：从「会聊天」到「替你记住事、管好时间」。*
*✅ 已落地（2026-11）：番茄钟+专注统计（focus.json）、提醒持久化+每日重复+取消（reminders.json）、全局快捷键 Ctrl+Alt+P（Windows）、截图问小墨、意图协议文档化（docs/意图协议.md）。*

- **番茄钟 + 专注统计**：「陪我专注 25 分钟」→ 到点休息提醒 + 当日专注时长统计（与久坐数据打通）
- **日程提醒升级**：一句话提醒已支持绝对时间（14:30）；补上「每天/每周重复」与跨天持久化（重启不丢）
- **全局快捷键**：一键唤起聊天窗 / 截图问 AI，不用去找猫
- **截图问答产品化**：图片上传已支持多模态，包装成「圈选屏幕问小墨」——高频刚需
- **意图协议开放**：把 `{"action": ...}` 协议文档化，为插件生态铺路

### v2.2 「陪伴」——情感纵深（1~2 月）
*目标：让用户与宠物之间有「记忆」和「关系」。*
*✅ 已落地（2026-11）：成长体系（互动积分→等级/形态，growth.json + 统计面板）、回忆录（每周本地聊天周报，weekly.json）、语音说话 TTS（Windows System.Speech / macOS say，音量语速进设置）。*
*⏳ 待做：主动关怀（天气/节气本地 API）、心情细化（不同心情不同 idle 动画权重）。*

- **成长体系**：喂食/抚摸/陪伴天数积累 → 等级与形态变化（小猫→成猫），掉线太久会「想你」
- **回忆录**：每周日推送「本周我们聊了 N 句，你问我最多的是…」（本地数据，AI 生成周报）
- **主动关怀**：接入天气/节气（本地 API）——「今天降温了，出门加件衣服」
- **语音说话（TTS）**：提醒和回复可以开口说（Windows TTS 免费）；音量/开关进设置
- **心情再细化**：从三维数值走向可见的情绪表达（不同心情不同 idle 动画权重）

### v2.3 「生态」——开放与个性化（2 月+）
- **皮肤工坊**：素材包格式 + 社区分享；皮肤是这类产品最成熟的付费点
- **插件系统**：第三方注册新的 `action`（如「打开网站」「控制音乐」），工具层直接复用
- **语音输入（STT）**：对着小猫说话发消息
- **手机伴侣（远期）**：提醒同步到手机，人不在电脑前也不错过

## 3. 商业化设想（保持 BYOK 底线）

| 层 | 内容 | 定价思路 |
|---|---|---|
| 免费 | 全部核心：聊天、提醒、漫游、本地小脑 | 建立口碑与装机量 |
| 皮肤/形象付费 | 精品皮肤、专属动画、宠物种类 | 单买或月费，美学付费意愿最强 |
| 高级助理 | 云端模型代充（不想自己办 Key 的用户）、TTS 音色包 | 按量或订阅 |

**底线**：本地数据不上传、BYOK 永远保留——这是信任根基，动它等于自杀。

---

## 4. 北极星指标与护栏

- **北极星**：周活跃天中「有效互动天数」（提醒被确认 / 发过消息 / 用过任一工具）
- **护栏指标**：空闲 CPU、通知关闭率（用户关提醒 = 打扰失衡的强信号）、7 日留存
- **健康信号**：本地小脑使用占比（隐私卖点是否成立）、多模型方案配置率（高级功能渗透）

## 5. 风险与对策

| 风险 | 对策 |
|---|---|
| 通知疲劳 → 被卸载 | 统一驻留已做；下一步：勿扰时段设置 + 通知中心可选 |
| AI 成本转嫁给用户后的体验断层 | 未配 Key 的本地小脑必须持续可用且不难堪 |
| 桌宠品类同质化 | 活物感 + 工具执行层双壁垒，避免纯「卖萌播放器」 |
| 单人维护节奏 | 每个版本只做一个主题，测试覆盖不放松（当前 1066 用例是资产） |
